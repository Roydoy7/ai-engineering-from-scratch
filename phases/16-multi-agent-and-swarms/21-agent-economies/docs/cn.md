# 智能体经济、代币激励与声誉（Agent Economies, Token Incentives, Reputation）

> 长时域自主智能体（METR 的 1 小时到 8 小时工作曲线）需要经济能动性。新兴的 **5 层栈**是：**DePIN**（物理计算）→ **身份**（W3C DIDs + 声誉资本）→ **认知**（RAG + MCP）→ **结算**（账户抽象）→ **治理**（智能体 DAO）。生产级智能体激励网络包括：**Bittensor**（TAO 子网奖励特定任务模型）、**Fetch.ai / ASI 联盟**（ASI-1 Mini LLM + FET 代币）和 **Gonka**（基于 Transformer 的 PoW，将计算重新分配给生产性 AI 任务）。学术工作：AAMAS 2025 的去中心化 LaMAS 使用 **Shapley 值信用归因**来公平奖励贡献智能体；谷歌研究"大型语言模型的机制设计"在单调聚合下提出带二价支付的**代币拍卖**。本课构建一个最小化的智能体市场，将 Shapley 值信用归因应用于多智能体流水线，并运行二价代币拍卖，使博弈论机制具体落地。

## 问题所在

当智能体共同产生价值但需要单独奖励时，多智能体系统变得复杂。经典机制——平均分配、最后贡献者通吃——要么不公平，要么可被操纵。通过 Shapley 值进行联盟式奖励从构造上是公平的，但计算成本昂贵。2025-2026 年的文献推动了实用近似：Shapley 采样、单调聚合拍卖，以及从确认贡献中积累的链上声誉。

除了信用归因，该领域已转向真实的经济智能体：Bittensor TAO 奖励挖矿计算以微调子网特定模型，Fetch.ai/ASI 用 FET 代币奖励 ASI-1 Mini LLM 使用，Gonka 将 Transformer 工作量证明重新导向生产性 AI 任务。自主交易的智能体今天已经存在；问题在于如何对齐激励。

本课将智能体经济视为一个具体的问题家族——信用归因、机制设计和声誉——用最少的数学构建每一个，让思想真正落地。

## 核心概念

### 5 层智能体经济栈

1. **DePIN（去中心化物理基础设施）。** 租用 GPU、存储、带宽的去中心化基础设施。Bittensor 子网、Render 网络、Akash。不是智能体专属的；智能体使用它。
2. **身份。** W3C 去中心化标识符（DIDs）给每个智能体一个独立于任何平台的持久 ID。声誉积累到 DID 上。智能体网络协议（ANP）使用 DID 作为发现层。
3. **认知。** 智能体的推理循环：LLM + RAG + MCP。这是其他阶段构建的内容。
4. **结算。** 账户抽象（ERC-4337）让智能体从自己的余额中支付 gas，而无需持有 ETH。智能体可以为服务、彼此或计算付费。
5. **治理。** 智能体 DAO：治理结构，其中人类*和*智能体都对协议变更进行投票，投票权与声誉挂钩。

并非每个生产系统都使用全部五层。Bittensor 使用 1、2、部分 3、部分 4，不使用 5。OpenAI 智能体除了 3 之外都不使用。该栈是参考地图，而非要求。

### Bittensor、Fetch.ai、Gonka——运行中的系统

**Bittensor（TAO）。** 子网是专业任务（语言建模、图像生成、预测）。矿工提交模型输出。验证者对其进行排名；质押加权评分分发 TAO 奖励。每个子网有自己的评估。经济学教训：按任务特定的输出质量付费，而非按使用的计算付费。

**Fetch.ai / ASI 联盟。** ASI-1 Mini LLM 在 Fetch.ai 的网络上运行；用户支付 FET 代币进行推理。智能体作为同伴的叙事在这里更强：Fetch 上的智能体可以为任务调用另一个智能体并用 FET 支付。

**Gonka。** Transformer 工作量证明：所做的"工作"是 Transformer 的前向传递。矿工通过运行具有已知正确输出的推理任务（来自训练数据）来赚取收益。基于资源的生产性 PoW，而非基于哈希的 PoW。

截至 2026 年 4 月，三者都是生产级的。回报分配方式不同。Bittensor 相对于子网验证者奖励质量；Fetch 按付费用户衡量的效用奖励；Gonka 奖励可验证的推理工作。

### Shapley 值信用归因

三个智能体合作完成一项任务。输出得分 0.8。谁贡献了什么？

Shapley 值：满足四个公理（效率、对称、线性、空）的唯一信用分配。对于智能体 `i`：

```
shapley(i) = (1/N!) * 在所有排列 O 上求和 (v(S_i_O ∪ {i}) - v(S_i_O))
```

其中 `S_i_O` 是排列 `O` 中在 `i` 之前的智能体集合。实践中：枚举所有排列，记录每个智能体在每个排列中的边际贡献，然后取平均值。

对于 N=3 个智能体，有 6 种排列。对于 N=10，有 360 万种——所以实践中你对排列进行采样而非枚举。

### 聚合的二价拍卖

谷歌研究（"大型语言模型的机制设计"）提出了用于聚合 LLM 输出的二价代币拍卖。设置：N 个智能体各自提出一个补全；每个人都有一个被选中的私人价值。拍卖者选择价值最高的提案，并支付*第二高的*价值。在单调聚合下（价值取决于选择哪个提案，而非竞标了多少），这是真实的——智能体如实报告其真实价值。

为什么这对 LLM 系统很重要：你可以将补全任务外包给具有不同定价的多个智能体；拍卖选择最佳者并公平支付，智能体没有虚报的动机。

### 声誉资本

绑定到 DID 的声誉分数从确认的贡献中积累。一个简单的更新规则：

```
rep(i, t+1) = alpha * rep(i, t) + (1 - alpha) * contribution_quality(i, t)
```

衰减因子 `alpha` 接近 1。声誉：

- 读取成本低，可用于路由决策（"将困难任务发送给高声誉智能体"）。
- 难以伪造（随时间积累，绑定到 DID）。
- 可被削减：验证失败的贡献会扣分。

### AAMAS 2025 去中心化 LaMAS

LaMAS 提案（AAMAS 2025）结合了：DID 身份、Shapley 值信用归因和简单拍卖机制。核心主张：去中心化信用归因步骤使系统可审计，且不受单点操纵。

### 经济学失效的地方

- **价格预言机操纵。** 如果信用函数可以被操纵，智能体就会去操纵它。每种机制都需要对抗性测试。
- **女巫攻击。** 一个运营商启动 N 个假智能体来夸大自己的贡献。DIDs 减缓但不能阻止这种情况；伪造声誉的成本才是缓解手段。
- **验证成本。** 信用归因的公平性只取决于验证者的公平性。如果验证便宜（小型 LLM），可以被操纵；如果昂贵（人类小组），系统无法扩展。
- **监管悬而未决。** 智能体经济与金融监管交叉。Bittensor、Fetch 和 Gonka 截至 2026 年在某些司法管辖区都在法律灰色地带运营。

### 何时智能体经济有意义

- **具有异质运营商的开放网络。** 没有单一团队控制所有智能体。
- **可验证的输出。** 没有验证，信用归因就是猜测。
- **长时域工作流。** 一次性任务不能从声誉积累中受益。
- **代币化支付在你的司法管辖区法律上可行。**

在封闭的企业系统中，经济学让位于更简单的分配（管理者分配工作，指标是内部的）。经济学文献主要适用于开放网络。

## 交付它

2026 年运营智能体经济：

- **从声誉开始，而非代币。** 声誉实现成本低且单独就有价值；代币增加了法律和经济复杂性。
- **先验证再奖励。** 没有独立验证步骤，永远不要分配信用。自我报告的质量会招致女巫攻击。
- **Shapley 采样，而非精确 Shapley。** 采样 100-1000 个排列；精确枚举无法扩展。
- **限制衰减因子并设置声誉下限。** 无限制的衰减会抹去合法贡献者；太慢的衰减会奖励过时的高声誉智能体。
- **对抗性地审计机制。** 在开放网络之前运行红队场景。每种机制都有博弈论；你希望找到漏洞，而不是让攻击者来找。

1. 运行 `code/main.py`。确认 Shapley 值之和等于总价值（效率公理）。改变价值函数；Shapley 分配是否按预期方向变化？
2. 实现 Shapley *采样*（对 K 个排列进行蒙特卡洛采样）。K 如何影响近似精度？对 N=4 与精确值进行比较。
3. 在拍卖之前实现联盟形成步骤：智能体可以合并成团队并作为一个单位竞标。哪些联盟会形成？结果是否比单独竞标帕累托更优？
4. 阅读谷歌研究的机制设计文章。识别一个如果被违反就会破坏真实性的假设。在 LLM 环境中，这种失效模式是什么样子的？
5. 阅读 AAMAS 2025 去中心化 LaMAS 论文。在 10 个智能体的合成任务上实现他们的 Shapley 步骤。精确计算需要多长时间？100 次采样能近似到多接近？

## 关键术语

| 术语 | 通俗说法 | 准确含义 |
|------|----------|----------|
| DePIN | "去中心化物理基础设施" | 代币激励的计算/存储/带宽。Bittensor、Akash、Render。 |
| DID | "去中心化标识符" | W3C 规范，用于可移植 ID。智能体声誉绑定到 DID，而非平台。 |
| ERC-4337 | "账户抽象" | 可以赞助 gas 的合约账户，使智能体支付成为可能。 |
| Shapley value（Shapley 值） | "公平信用归因" | 满足效率、对称、线性、空的唯一分配。 |
| Second-price auction（二价拍卖） | "Vickrey 拍卖" | 真实机制：获胜者支付第二高的竞标。与单调聚合兼容。 |
| Reputation capital（声誉资本） | "积累的质量分数" | 来自确认贡献的 DID 绑定分数；随时间衰减。 |
| Agentic DAO（智能体 DAO） | "智能体 + 人类治理" | 以智能体投票者为一等公民的 DAO，投票权与声誉挂钩。 |
| TAO / FET / GPU 积分 | "代币面值" | Bittensor TAO、Fetch.ai FET、各种 DePIN 代币。 |
