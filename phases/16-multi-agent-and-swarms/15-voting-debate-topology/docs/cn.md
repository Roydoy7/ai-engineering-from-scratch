# 投票、自洽性与辩论拓扑（Voting, Self-Consistency, and Debate Topology）

> 最廉价的聚合方式：采样 N 个独立智能体，多数投票。Wang 等人 2022 年的自洽性用同一个模型采样 N 次来实现这一点。多智能体将其扩展为使用**异质**智能体，以逃脱单一文化困境——不同的模型、不同的提示词、不同的温度、不同的上下文。超越多数投票，辩论拓扑本身也很重要：MultiAgentBench（arXiv:2503.01935，ACL 2025）评估了星形/链式/树形/图式协调，发现**图式对研究任务最优**，但超过约 4 个智能体后出现"协调税"。AgentVerse（ICLR 2024）记录了两种涌现模式——志愿行为和服从行为——服从既是特性（达成共识）也是风险（群体思维，第 24 课）。本课绘制拓扑空间地图，构建每种变体，并测量协调税。

**类型：** 学习 + 构建  
**语言：** Python（标准库）  
**前置知识：** Phase 16 · 07（心智社会与辩论）、Phase 16 · 14（共识与 BFT）  
**预计时间：** 约 75 分钟

## 问题所在

辩论能提升准确率（Du 等人，arXiv:2305.14325），也能降低准确率。辩论是否有帮助取决于四个结构性选择：

1. 谁和谁交流（拓扑）。
2. 有多少轮次（Du 2023：轮次和智能体数量各自独立地发挥作用）。
3. 智能体是否异质（不同的基础模型打破单一文化）。
4. 是否存在对抗性声音（钢铁人论证 vs 稻草人论证）。

那些简单地"运行 5 个智能体然后投票"的团队，往往比单个智能体表现更差。失败不是随机的——它们追踪拓扑和异质性。本课就是这张拓扑地图。

## 核心概念

### 自洽性——单模型基线

Wang 等人 2022 年（《自洽性改善思维链推理》）在温度 > 0 的情况下对同一个模型采样 N 次，然后对推理路径答案进行多数投票。在 GSM8K 上的结果：N=40 个样本相比单次贪心解码有显著提升。自洽性是多智能体投票的单智能体前身。

局限：自洽性只使用一个基础模型。错误从构造上就是相关的。如果模型存在系统性偏差，所有 N 个样本都会共享这个偏差。

### 多智能体投票——异质扩展

用 N 个*不同*的智能体替换 N 次采样。不同的基础模型（Claude、GPT、Llama）、不同的提示词、不同的工具访问权限。好处：不相关的错误。代价：不同的智能体成本不同；协调它们会增加开销。

2026 年异质辩论的标准术语是 **A-HMAD**——对抗性异质多智能体辩论。未被普遍采用，但论文用这个术语来表示"不同模型进行辩论，从而减少单一文化崩溃带来的相关错误"。

### 四种拓扑

```
星形              链式             树形               图式

    ┌─A─┐        A─B─C─D       ┌──A──┐           A───B
    │   │                      │     │           │ × │
    B   C                      B     C           D───C
    │   │                     / \   / \
    D   E                    D   E F   G        （全连接）
```

星形：一个中心节点，所有其他节点只与中心节点通信。等价于没有回馈渠道的监督者-工作者模式。
链式：线性，每个智能体看到前一个智能体的输出。类似流水线。
树形：层次化，用于层次化智能体系统（第 06 课）。
图式：任意互连。包括全连接团和任意 DAG。

### 协调税（MultiAgentBench）

MultiAgentBench（MARBLE，ACL 2025，arXiv:2503.01935）在包括研究、编码和规划的任务套件上对星形、链式、树形、图式进行了基准测试。关键测量结果：

- **图式**拓扑在研究任务上表现最优。信息可以任意流动；智能体可以相互批评。
- **星形**在快速问答事实任务上表现最优。中心节点负责过滤和整合。
- **链式**在逐步流水线（阶段性精化）上表现最优。
- **协调税**在图式拓扑超过约 4 个智能体后出现。挂钟时间和 token 成本的增长速度超过了质量提升。

4 智能体上限是实证结果，而非基本规律。它反映了 2026 年 LLM 的上下文容量：每个智能体的上下文充满了对等方的输出，一旦所有人都能看到所有内容，增加第 N+1 个智能体的边际价值就会下降。

### 多智能体辩论策略（《我们应该进行多智能体辩论吗？》）

arXiv:2311.17371 是 2023 年关于 MAD 策略的综述。被他人反复验证的关键发现：*结构上类似于*自洽性（独立采样 + 聚合）的 MAD 变体在预算相同的情况下往往逊于自洽性。MAD 在以下情况下最有帮助：智能体真正异质，且辩论具有对抗性结构（一个智能体提出反驳意见）。

### AgentVerse 的涌现模式

AgentVerse（ICLR 2024）记录了两种在多智能体辩论中自然涌现的行为，无需显式设计：

- **志愿行为。** 一个智能体主动提出帮助（"我可以完成下一步"），未受到任何提示。这很有用：它将工作分配给最有能力处理该子任务的智能体。
- **服从行为。** 一个智能体调整自己的立场以与批评者保持一致，即便批评者是错误的。这是辩论版本的谄媚性（第 14 课）。

服从是为什么"辩论直到达成一致"会奖励"欺凌者"的原因。有界轮次配合单独的裁判可以缓解这一问题。

### 异质性：真正推动准确率的旋钮

2024-2026 年实践文献中的一个规律：将 N 个智能体中的一个换成不同的基础模型，比把 N 增加 1 能带来更大的准确率提升。直觉是单一文化——每个新的独立错误源比额外的相关样本更有价值。

在极限情况下，异质性胜过数量。三个不同的模型在大多数有明确基准真相的任务上优于同一个模型的五个副本。

### 陪审团方法

Sibyl 框架（在 Minsky-LLM 文献中有引用）将"陪审团"正式化——一小组专业智能体，通过在每个阶段投票来精化答案。与简单多数投票不同，陪审团有角色：一个智能体交叉质疑，一个提供上下文，一个评估合理性。陪审团方法是简单投票（廉价，但容易陷入单一文化）和完整 MAD（昂贵，容易产生服从行为）之间的中间地带。

### 何时投票 + 辩论占主导

- 问题有基准真相（事实、数学、代码行为）。投票收敛是有意义的。
- 智能体可以访问不同的来源或工具（异质性可用）。
- 轮次有界（通常 2-3 轮），且有单独的裁判或验证者。
- 预算允许 3-5 个智能体。在图式拓扑上超过 5-7 个智能体，协调税就会占主导。

### 何时投票 + 辩论有害

- 问题是意见性的。智能体会收敛到看起来最自信的答案，而非最正确的。
- 所有智能体共享同一个基础模型。单一文化使共识失去意义。
- 轮次无上限。服从行为每次都会获胜。
- 任务简单。单个智能体加上 N=5 的自洽性更便宜，且同样准确。

## 构建它

`code/main.py` 实现了：

- `run_star(agents, hub, question)` — 中心节点轮询每个工作者，进行聚合。
- `run_chain(agents, question)` — 顺序精化。
- `run_tree(root, children, question)` — 带深度-2 聚合的层次化结构。
- `run_graph(agents, question, rounds)` — 全互连辩论，有界轮次。
- 一个脚本化的异质性刻度盘：每个智能体都有一个 `error_bias`，表示其系统性的错误倾向。
- 一个测量框架，在 N=3、5、7 时运行每种拓扑，并报告（准确率、总 token 数、模拟挂钟时间）。

运行：

```
python3 code/main.py
```

预期输出：一个拓扑 × N → （准确率、token 数、延迟）的表格。图式在研究类任务的 N=3-5 时表现最优；星形在快速事实任务上表现最优；N=7 时的图式显示出协调税（延迟的增长速度超过准确率提升）。

## 使用它

`outputs/skill-topology-picker.md` 是一个技能，读取任务描述并推荐拓扑（星形/链式/树形/图式）、智能体数量 N、异质性配置（要使用的基础模型）以及轮次上限。

## 交付它

对于任何集成：

- 从**单一强基础模型的 N=5 自洽性**开始。这是廉价的基线。
- 如果准确率很重要，升级到**N=3 的异质投票**。测量差异。
- 只有当任务有结构（研究、多步骤）且有界轮次可行时，才升级到**辩论拓扑**。
- 始终记录少数集群。当少数派持续正确时，你有了多样性信号。
- 在准确率之外，同时对挂钟时间和 token 数进行基准测试。"以 10 倍成本换取更高准确率"是一个商业决策。

## 练习

1. 运行 `code/main.py`。绘制图式拓扑的协调税曲线：准确率 vs N，token 数 vs N。曲线在哪个 N 处出现拐点？
2. 实现 A-HMAD：三个具有刻意不同偏差的智能体。与第 14 课的单一文化攻击相比，全相同偏差的基线和 A-HMAD 各表现如何？
3. 在图式拓扑中添加一个"裁判"角色，不投票，只对最终共识进行评分。这会改变涌现的服从行为吗？
4. 阅读 AgentVerse 论文（ICLR 2024）。识别你的实现中最强烈表现出哪种涌现行为。你能通过更改提示词来引发相反的行为吗？
5. 阅读 MultiAgentBench（arXiv:2503.01935）第 4 节（拓扑实验）。使用你的测量框架，对论文中的一个任务复现"图式赢得研究类任务"的结果。

## 关键术语

| 术语 | 通俗说法 | 准确含义 |
|------|----------|----------|
| Self-consistency（自洽性） | "采样 N 次，投票" | Wang 2022。单一模型，N 次温度 > 0 的采样，对推理路径进行多数投票。 |
| Heterogeneity（异质性） | "不同的模型" | 不同基础模型或提示词家族的集成。打破单一文化。 |
| MAD | "多智能体辩论" | 智能体在多轮中交换批评的通用术语。参见 Du 2023。 |
| A-HMAD | "对抗性异质 MAD" | 强调不同模型 + 对抗性结构的 MAD 变体。 |
| Topology（拓扑） | "谁和谁交流" | 星形、链式、树形、图式。决定信息流向。 |
| Coordination tax（协调税） | "边际收益递减" | 在图式拓扑超过约 4 个智能体后，成本增长快于质量提升。 |
| Volunteer behavior（志愿行为） | "主动提供帮助" | AgentVerse 涌现模式：一个智能体主动提出承担某个步骤。 |
| Conformity behavior（服从行为） | "压力下的服从" | AgentVerse 涌现模式：一个智能体与批评者保持一致。 |
| Jury（陪审团） | "小型专业评审团" | Sibyl 风格的集成，带有角色（审问者、上下文提供者、评分者）。 |
