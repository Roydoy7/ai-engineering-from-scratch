# 面向 LLM 的群体优化（PSO、ACO）（Swarm Optimization for LLMs: PSO, ACO）

> 生物启发优化正在 LLM 领域卷土重来。**LMPSO**（arXiv:2504.09247）使用 PSO，其中每个粒子的速度是一个提示词，LLM 生成下一个候选结果；在结构化序列输出（数学表达式、程序）上效果良好。**Model Swarms**（arXiv:2410.11163）将每个 LLM 专家视为模型权重流形上的 PSO 粒子，报告在 9 个数据集、12 个基线上仅用 200 个实例取得了 **13.3% 的平均提升**。**SwarmPrompt**（ICAART 2025）将 PSO 与灰狼算法混合用于提示词优化。**AMRO-S**（arXiv:2603.12933）是用于多智能体 LLM 路由的 ACO 启发信息素专家系统——**4.7 倍加速**、可解释的路由证据，以及将推理与学习解耦的质量门控异步更新。本课在提示词参数空间实现 PSO，在智能体路由上实现 ACO，测量这些经典算法为何适合 LLM 时代，以及何时不适合。

**类型：** 学习 + 构建  
**语言：** Python（标准库）  
**前置知识：** Phase 16 · 09（并行群体网络）、Phase 16 · 14（共识与 BFT）  
**预计时间：** 约 75 分钟

## 问题所在

你有一个在任务评估上得分 62% 的提示词。你想改进它。朴素的做法是无梯度的手动微调，扩展性很差。强化学习需要奖励信号和足够的 rollout 来训练。通过提示词反向传播并不现实——提示词是离散字符串，不是可微参数。

经典的生物启发优化——PSO 用于连续搜索空间，ACO 用于路径选择——正是为这种场景设计的：无梯度、基于种群、每次评估成本低廉。将它们与 LLM 配对进行无梯度搜索步骤，你会得到一个出人意料地实用的优化器。

同样的模式也适用于多智能体系统中的智能体*路由*。ACO 风格的信息素轨迹记录了哪个智能体在哪种任务类型上效果最好，让路由器利用这条轨迹，并随时间衰减信息素，使路由得以被重新发现。

## 核心概念

### PSO 复习（Kennedy & Eberhart 1995）

粒子群优化：在连续搜索空间中的粒子种群。每个粒子有位置 `x_i` 和速度 `v_i`。每次迭代：

```
v_i <- w * v_i + c1 * r1 * (p_best_i - x_i) + c2 * r2 * (g_best - x_i)
x_i <- x_i + v_i
评估 fitness(x_i)
如果改进则更新 p_best_i
如果全局最优则更新 g_best
```

其中 `p_best` 是粒子自己的历史最优，`g_best` 是群体历史最优，`w, c1, c2` 是惯性 + 认知 + 社会权重，`r1, r2` 是随机因子。

### LLM 输出上的 PSO——LMPSO

arXiv:2504.09247 将 PSO 适配用于 LLM 生成的结构化输出（数学表达式、程序）。每个粒子是一个候选输出。速度是一个*提示词*，描述如何将当前输出修改向个人/全局最优靠拢。LLM 从速度提示词生成新输出。速度的"惯性"是一个类似"做小幅增量修改"的提示词。

这在以下情况下效果良好：
- 输出是结构化的（可解析、可评估）。
- 适应度是自动的（测试运行、算术评估）。
- 种群很小（约 10-30 个粒子），使总 LLM 调用次数保持在可控范围内。

当适应度需要人工审查时效果不佳——每次迭代的成本变得过高。

### Model Swarms

arXiv:2410.11163 将 PSO 从输出层移到*模型*层。每个"粒子"是一个专家 LLM（参数）。群体通过无梯度更新将参数移向集体最优。报告：在 9 个数据集、12 个基线上，仅用每次迭代 200 个实例取得了 13.3% 的平均提升。

关键洞察是 LLM 专家模型在共享参数流形中已经很接近（适配器权重、LoRA 增量）。在这个低维子空间上的 PSO 既廉价又有效。

### ACO 复习（Dorigo 1992）

蚁群优化：蚂蚁遍历一个图；每条路径都有一条信息素轨迹。蚂蚁移动的概率按信息素强度加权。完成任务的蚂蚁按解决方案质量沉积信息素。信息素随时间衰减。

### AMRO-S——用于智能体路由的 ACO

arXiv:2603.12933 将 ACO 用于多智能体路由。每种任务类型是一个"目标"；每个智能体是一条可能的路由。信息素加强能产生良好输出的路由。关键贡献：

- **可解释的路由证据。** 信息素强度是一个人类可读的信号。
- **质量门控异步更新。** 信息素只在质量检查通过后才更新，将推理与学习解耦。
- 在多智能体路由基准测试上实现了 **4.7 倍加速**。

质量门控很重要：没有它，快速但错误的智能体会积累信息素，系统会锁定在错误的路由上。

### 何时对 LLM 使用 PSO / ACO

**使用 PSO 的场景：**
- 搜索空间是连续的，或可映射到连续参数（提示词嵌入、LoRA 权重、数值生成参数）。
- 适应度廉价且自动化。
- 种群可以很小（10-30）。

**使用 ACO 的场景：**
- 你有路由或路径选择问题。
- 决策随时间强化（相同类型的任务反复出现）。
- 你需要路由决策的可解释证据。

**不使用两者的场景：**
- 适应度需要人工审查（每次迭代太贵）。
- 搜索空间是离散且组合式的，PSO 无法覆盖（改用遗传算法）。
- 实时决策需要严格的延迟（PSO/ACO 相对于单次启发式收敛较慢）。

### 为什么生物启发方法仍然获胜

基于梯度的方法需要可微信号。LLM 输出和路由决策并不容易微分。伪梯度方法（强化学习路由器、DPO 风格的提示词调优器）有效，但需要昂贵的训练。

PSO 和 ACO 只需要一个*评估器*函数。如果你能对候选输出或路由决策进行评分，就可以在该空间上进行优化。这使得适用门槛低得多。

### 实际限制

- **种群预算。** N 个粒子 × T 次迭代 × 每次评估成本。对于约 $0.02 / 次调用的 LLM 评估，一个 20 粒子的 PSO 运行 50 次迭代将花费约 $20。要做好规划。
- **探索 vs 利用。** 信息素衰减率和 PSO 惯性进行权衡；衰减太快 → 遗忘解决方案；太慢 → 陷入早期局部最优。
- **灾难性漂移。** 如果适应度景观改变（新数据分布），两种算法都可能收敛后再发散。监控最优适应度的稳定性。

## 构建它

`code/main.py` 实现了：

- `LMPSO` — 在数值提示词参数（温度、top_k 权重）上的 PSO。每个粒子的"LLM 生成"被模拟为脚本化的适应度函数。运行 30 次迭代并显示 g_best 收敛。
- `AMRO_S` — ACO 风格路由。3 个智能体，4 种任务类型，信息素矩阵，100 个路由的任务。打印随时间变化的（任务类型 → 智能体选择）分布，以显示轨迹形成过程。
- 对比：在相同任务流上进行随机路由 vs ACO 路由。测量质量和延迟。

运行：

```
python3 code/main.py
```

预期输出：
- LMPSO：g_best 适应度在 30 次迭代中从随机提升到接近最优。
- AMRO-S：信息素表在每种任务类型的正确智能体上稳定下来；ACO 路由在质量上优于随机约 30-40%，并且减少了延迟（更少的重试）。

## 使用它

`outputs/skill-swarm-optimizer.md` 帮助在 PSO、ACO、遗传算法和基于梯度的优化器之间做出选择，用于 LLM / 智能体优化问题。

## 交付它

- **从小开始。** 10-20 个粒子，20-50 次迭代。只有当收敛曲线显示出明显收益时才扩大规模。
- **记录每次迭代的信息素或 g_best。** 没有轨迹地调试群体优化器是很痛苦的。
- **质量门控更新。** 特别是对于 ACO 路由：快速但错误的智能体不能积累信息素。
- **在分布转移时重置衰减。** 当你的评估分布改变时，旧的信息素已经过时；暂时重置或加倍衰减率。
- **限制每次迭代的成本。** 发出每次迭代成本指标。每次迭代花费 $500 却只获得 0.5% 提升的 PSO 无法上线。

## 练习

1. 运行 `code/main.py`。观察 LMPSO 的收敛。改变种群大小为 5、10、20、50。在哪个大小时收敛时间趋于饱和？
2. 实现"灾难性漂移"实验：在第 30 次迭代后，改变适应度函数。PSO 适应的速度有多快？重置 `p_best` 有帮助吗？
3. 为 AMRO-S 添加质量门控：只有当评估分数 > 0.7 时才沉积信息素。与未门控的版本相比，这如何改变收敛？
4. 阅读 LMPSO（arXiv:2504.09247）。将论文的"速度即提示词"映射回你的数值速度。在模拟中丢失了什么，保留了什么？
5. 阅读 AMRO-S（arXiv:2603.12933）。实现解耦的"推理快速路径"和异步信息素更新。这在持续负载下如何改变系统延迟？

## 关键术语

| 术语 | 通俗说法 | 准确含义 |
|------|----------|----------|
| PSO | "粒子群优化" | Kennedy-Eberhart 1995。基于种群的无梯度优化器。 |
| ACO | "蚁群优化" | Dorigo 1992。通过信息素轨迹进行路径/路由优化。 |
| LMPSO | "带 LLM 生成的 PSO" | arXiv:2504.09247。速度是提示词；LLM 产生候选结果。 |
| Model Swarms | "专家权重上的 PSO" | arXiv:2410.11163。在模型参数子空间上的无梯度更新。 |
| AMRO-S | "用于智能体路由的 ACO" | arXiv:2603.12933。任务类型 × 智能体的信息素矩阵。 |
| p_best / g_best | "个人/全局最优" | 每个粒子和整个群体迄今为止找到的最优解。 |
| Pheromone（信息素） | "路由记忆" | 边上的强度；随时间衰减；按质量沉积。 |
| Quality-gated update（质量门控更新） | "只从好的运行中学习" | 以质量检查为条件的信息素沉积。 |
| Catastrophic drift（灾难性漂移） | "分布转移" | 适应度景观改变；旧的 p_best 和信息素变得过时。 |
