# 心智社会与多智能体辩论（Society of Mind and Multi-Agent Debate）

> Minsky 在 1986 年提出的前提——智能是一个专家社会——每隔十年就会被重新发现一次。2023 年，Du 等人将其转化为具体算法：多个 LLM 实例各自提出答案，相互阅读对方的答案，进行批评，然后更新自己的观点。经过 N 轮迭代后，它们会收敛到一个共识，在六项推理和事实性任务上超越零样本思维链（CoT）和反思法。两个发现至关重要：**多个智能体**和**多轮次**分别独立贡献了收益。社会的表现优于单智能体的独白；多轮交流的表现优于一次性投票。

**类型：** 学习 + 构建  
**语言：** Python（标准库）  
**前置知识：** Phase 16 · 04（原语模型）  
**预计时间：** 约 60 分钟

## 问题所在

自洽性（Self-consistency）——多次采样同一个模型，取多数答案——是最廉价的推理增强手段。它有效，但很快就会饱和。把样本数量翻倍，往往看不到任何有意义的提升。

辩论打破了这种饱和。不是从一个模型取 N 个独立样本，而是让 N 个智能体互相阅读对方的推理并进行修订。样本之间的相关性下降了（它们不再是独立同分布的），而收敛点往往在独立同分布投票自信地得出错误答案的地方给出正确结果。

## 核心概念

### Du 等人 2023 年的算法

来自 arXiv:2305.14325（ICML 2024）：

1. N 个智能体各自对问题给出初始答案。
2. 对于第 r = 2..R 轮：每个智能体看到其他智能体在第 r-1 轮的答案，并被要求"考虑这些内容后，给出你更新后的答案"。
3. 经过 R 轮后，对最终答案进行多数投票。

该论文在 MMLU、GSM8K、传记、MATH 和事实性基准测试上进行了测试。辩论始终优于 CoT 和自我反思。

### 两个独立的旋钮

来自同一篇论文的消融实验：

- **单独增加智能体数量**（1 轮，对 N 个答案多数投票）在大多数任务上优于单智能体，但会趋于平台期。
- **单独增加轮数**（1 个智能体看到自己之前的推理）几乎没有帮助——这正是反思法的已知弱点。
- **两者结合**才产生大幅跃升。多个智能体之间的多轮交流驱动了真正的收益。

### 为什么有效

两个机制：

1. **接触分歧。** 当一个智能体看到另一个智能体得出不同结论的推理链时，它必须要么为自己的答案辩护，要么更新观点。无论哪种情况，第 r+1 轮的上下文都比第 r 轮更丰富。
2. **减少相关错误。** 在自洽性中，所有样本来自同一个模型，因此错误是相关的——你会对一个自信的错误答案取均值。不同的模型或不同的随机种子可以去相关。不同的*辩论观点*进一步去相关。

### 异质辩论

A-HMAD 及相关后续工作使用*不同基础模型*分配给不同智能体。Llama + Claude + GPT 共同辩论，能减少单一文化崩溃（第 26 课），因为一个模型家族的相关错误不会被其他模型共享。

缺点：参与辩论的弱模型可能会将共识拖向其错误答案（参见《我们应该进行多智能体辩论吗？》，arXiv:2311.17371）。

### NLSOM——129 智能体的扩展版本

Zhuge 等人（《自然语言心智社会中的思维风暴》，arXiv:2305.17066）将这一理念扩展到了 129 名成员的社会。结果：随着规模增长，专业化和自我组织自然涌现，系统在视觉问答等任务上超越了单智能体。

### 失效模式

- **谄媚级联（Sycophancy cascade）。** 所有智能体都向听起来最自信的那个智能体靠拢。辩论退化为"最大声的声音"赢。解决方法：通过提示词分配对抗性角色（"有一个智能体必须论证反方立场"）。
- **话题漂移。** 多轮辩论后，讨论会偏离原始问题。缓解措施：每轮重新注入原始问题。
- **计算爆炸。** N 个智能体 × R 轮 = N·R 次 LLM 调用，每次调用的上下文还在不断增长。5 个智能体 5 轮辩论就是 25 次调用，且上下文持续扩大。每个问题的成本可能超过单次 CoT 的 10 倍。

## 构建它

`code/main.py` 对一道数学题运行 3 个智能体 × 3 轮的辩论，每个智能体从一个不同（可能错误）的答案开始。智能体采用脚本化方式——每个智能体通过以预设置信度对邻居答案加权平均来进行"更新"。逐轮日志中可以清晰看到收敛过程。

演示展示了两个关键效应：

- 一轮交流就能让智能体向正确答案靠近。
- 第 2 轮之后的额外轮次呈现边际收益递减（与 Du 等人的平台期结论吻合）。

运行：

```
python3 code/main.py
```

## 使用它

`outputs/skill-debate-configurator.md` 为新任务配置辩论方案：智能体数量、轮数、异质性（同一模型还是混合模型）、角色分配（对称还是含一个对抗者）。在运行前还会估算 token 成本。

## 交付它

如果你要部署辩论：

- **将轮数上限设为 3。** Du 等人证明 3 轮能捕获大部分收益。更多轮数带来的是成本，而非质量。
- **将智能体数量上限设为 5。** 超过 5 个，上下文膨胀和成本就会占主导。
- **默认使用异质组合。** 模型池中至少包含两种不同的基础模型。
- **设置对抗性席位。** 一个智能体被提示无论如何都要提出反对意见，以打破谄媚效应。
- **记录每一轮。** 隐藏中间轮次的辩论系统无法被调试或审计。

## 练习

1. 运行 `code/main.py`，然后将轮数设为 5，观察边际收益递减。从哪一轮开始，额外的收敛停止了？
2. 添加第四个智能体扮演对抗角色：始终与当前多数意见相左。这会破坏还是改善收敛？
3. 绘制（打印）每轮的一致性得分（达成多数答案的智能体比例）。它在哪一轮达到 1.0？这等价于"正确"吗？
4. 阅读 Du 等人论文的第 4 节消融分析，用本代码复现"仅增加智能体"vs"仅增加轮数"vs"两者结合"的结果。
5. 阅读《我们应该进行多智能体辩论吗？》（arXiv:2311.17371），列出超越轮询辩论的两种变体——例如，裁判主导式、辩论链式、对抗式。

## 关键术语

| 术语 | 通俗说法 | 准确含义 |
|------|----------|----------|
| Society of Mind（心智社会） | "Minsky 的想法" | 将智能视为相互作用的专家群体；1986 年的框架现通过 LLM 辩论得以实现。 |
| Multi-agent debate（多智能体辩论） | "智能体们争论" | N 个智能体各自提出答案，经过 R 轮互相批评和修订，最后多数投票。 |
| Consensus（共识） | "它们达成一致" | 不是认知论意义上的真相——只是多数答案的占比。有可能自信地错误。 |
| Rounds（轮次） | "交流步骤" | 一轮 = 每个智能体阅读其他人的答案并更新一次。 |
| Heterogeneous debate（异质辩论） | "混合模型家族" | 使用不同基础模型以去相关错误。 |
| Sycophancy cascade（谄媚级联） | "所有人都同意最大声的那个" | 辩论失效模式，智能体不论正确性，都向最自信的智能体靠拢。 |
| NLSOM | "129 智能体社会" | 自然语言心智社会；Zhuge 等人的扩展版本。 |
| Correlated error（相关错误） | "同一模型，同一缺陷" | 自洽性饱和的原因；跨不同观点的辩论可以去相关。 |
