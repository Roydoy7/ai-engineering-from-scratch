# InternVL3：原生多模态预训练（InternVL3: Native Multimodal Pretraining）

> InternVL3 之前的每个开放 VLM 都遵循相同的三步方案：取一个在数万亿文本 token 上训练的文本 LLM，拼接一个视觉编码器，然后微调衔接处。这可行，但有对齐债务——文本 LLM 已将其全部预训练预算花在纯文本上，并不原生理解视觉 token。事后添加视觉时，LLM 必须重新学习如何将视觉输入与其文本推理相关联，同时还不能遗忘文本。InternVL3（Zhu 等，2025 年 4 月）拒绝了事后方法：一次预训练，从第一步起文本与多模态交错。结果是在 780 亿参数开放模型上匹配了 Gemini 2.5 Pro 的 MMMU-Pro 分数。本章解读原生预训练的理由以及实现它时发生的变化。

**类型：** 学习  
**语言：** Python（标准库，训练语料混合器）  
**前置知识：** Phase 12 · 05、Phase 12 · 07（方案）  
**预计时间：** 约 120 分钟

## 学习目标

- 解释为什么事后 VLM 训练会积累对齐债务，引用三个可量化的症状（灾难性遗忘、答案漂移、视觉-文本不一致）。
- 描述 InternVL3 的原生预训练语料混合以及文本：交错：描述的比例为何重要。
- 比较 V2PE（可变视觉位置编码）与 Qwen2-VL 的 M-RoPE。
- 说出视觉分辨率路由器（ViR）和解耦视觉-语言（DvD）部署优化。

## 问题所在

事后 VLM 训练是默认做法。LLaVA、BLIP-2、Qwen-VL、Idefics——都取一个已预训练的 LLM（Llama、Vicuna、Qwen、Mistral）然后添加视觉。训练阶段通常如下：

1. 冻结 LLM + 冻结视觉编码器 + 可训练投影器，在图文对上训练以对齐嵌入。
2. 解冻 LLM，在指令数据（LLaVA-Instruct、ShareGPT4V）上训练。
3. 可选的任务专属微调。

对齐债务会表现为三个症状：

- **灾难性遗忘。** 事后 VLM 会忘记纯文本技能。GSM8K 分数下降 5-10 分，Hellaswag 分数下降，纯文本智能体退化。
- **答案漂移。** 同一视觉问题的不同措辞得到不同答案。视觉编码器与 LLM 的绑定比 LLM 自身 token 弱。
- **视觉-文本不一致。** VLM 能正确描述图像，然后却回答出与自己描述矛盾的问题。视觉 token 不像文本那样参与 LLM 的内部一致性检查。

这些症状有充分记录。MM1.5 第 4 节对其进行了量化，LLaVA-OneVision 的消融实验也暗示了它们。原生预训练是答案。

## 核心概念

### 原生多模态预训练

InternVL3 从头在一个从第一步起就原生多模态的语料库上训练。混合比例为：

- 40% 纯文本数据（FineWeb、Proof-Pile-2 等）
- 35% 交错图文数据（OBELICS、MMC4 风格）
- 20% 图文对数据
- 5% 视频-文本数据

视觉 token、文本 token 和跨模态交互从第一个梯度步骤起就全部参与同一个损失。没有对齐预训练，没有投影器冻结阶段，没有需要从灾难性遗忘中恢复的过程。

基础模型是单阶段训练，之后进行指令微调，但基础模型已经将视觉 token 视为一等公民。

### V2PE（可变视觉位置编码）

Qwen2-VL 使用带固定轴分配的 M-RoPE。InternVL3 引入了 V2PE：位置编码根据模态类型（文本、图像、视频）变化，带有可学习的缩放。在实践中：

- 文本 token 获得一维位置（文本索引）。
- 图像图块获得二维位置（行、列）。
- 视频帧获得三维位置（时间、行、列）。

三者共享相同的 RoPE 频率基础，但每个频段的隐藏维度分配是可学习参数，而非固定分割。可以在预训练期间自由权衡时间与空间的频率分辨率。

V2PE 的消融声明：在相同算力下，视频基准比 M-RoPE 高 1-2 分。不是革命，但更干净。

### 视觉分辨率路由器（ViR）

部署优化。不是所有图像都需要全分辨率编码。一张低细节的单对象照片在 1280px 原生分辨率下编码会浪费 token。ViR 是一个小型分类器，在编码之前预测回答问题所需的最低分辨率。

路由有三个层级：低分辨率（256 token）、中等（576）、高（2048+）。在生产流量中，60% 的查询使用低或中等分辨率就足够。净效果：在相同质量下吞吐量提升 2-3 倍。

### 解耦视觉-语言部署（DvD）

在服务大型 VLM 时，视觉编码器每张图像运行一次，但 LLM 对每个输出 token 自回归运行。两个组件有不同的瓶颈（视觉 = 卷积 + 注意力的 GPU 内存带宽；LLM = KV 缓存）。DvD 将它们分到不同的 GPU 上，通过流式传输连接。

对于 80 亿 + 4 亿编码器模型，DvD 与共同部署相比大约使每节点吞吐量翻倍。

### 单阶段与多阶段的质量对比

InternVL3 的主要基准声明：在 780 亿参数下，匹配 Gemini 2.5 Pro 的 MMMU-Pro；在 380 亿参数下，匹配 GPT-4o；在 80 亿参数下，领先开放 8B 排行榜。全部基于单阶段预训练 + 指令微调方案。

对齐债务假说是可量化的：InternVL3-8B 每单位视觉基准提升损失的文本基准分数（MMLU、GSM8K）少于 Qwen2.5-VL-7B。模型更具通用性，因为训练是一个整体，而非两个阶段。

### InternVL3.5 与 InternVL-U

InternVL3.5（2025 年 8 月）扩展了方案：相同的原生预训练方法，更多数据，更多参数，MMMU 改进是渐进式的。

InternVL-U（2026）添加了统一生成——通过同一骨干上的 MMDiT 头实现图像输出。"U"代表"理解 + 生成"，追求 Transfusion 风格的统一模型（Lesson 12.13）。相同的原生预训练骨干同时支持理解和生成头。

### 原生预训练的权衡

原生预训练不是免费的：

- **算力。** 从头训练新 VLM 的成本与训练文本 LLM 相同——数百万 GPU 小时。事后适应复用现有 LLM 权重，节省了大部分成本。
- **数据。** 大规模交错图文语料库很稀缺。OBELICS 有 1.41 亿文档，MMC4 有 5.71 亿文档。纯文本有 15T token。多模态预训练数据稀缺是硬约束。
- **基础 LLM 复用。** 原生预训练放弃了之后引入新 LLM 的选项。事后方法可以通过只重训适配器来将 Llama-3.1 换成 Llama-4。

InternVL3 的赌注：对齐债务比复用损失更严重。基准支持这一声明。生产成本阻止了未来实验室廉价复制。事后 VLM 将继续存在，因为对大多数项目来说它们仍然更便宜。

## 动手使用

`code/main.py` 是训练语料混合器和 ViR 路由器模拟器。它：

- 接受目标语料混合（%文本、%交错、%描述、%视频）并计算每个模态的预期步骤数。
- 在一批查询上模拟 ViR 路由（分布：50% 低细节、30% 中等、20% 高细节），并报告平均 token 数。
- 给定编码器与 LLM FLOPs，报告 DvD 吞吐量估计。
- 打印事后训练与原生预训练在参数、算力、数据和预期对齐债务症状上的对比。

1. 估计 InternVL3-8B（原生预训练）与 LLaVA-OneVision-7B（事后）之间的算力差异。GPU 小时的大致比例是多少？是什么解释了这一差距？

2. InternVL3 报告 40% 文本 / 35% 交错 / 20% 描述 / 5% 视频。如果目标任务以视频为主，提出一个新比例，并论证为什么基础模型仍然需要大量文本和描述数据。

3. 阅读 MM1.5 第 4 节关于遗忘的内容。说出事后训练表现出最大回归的确切基准。回归代价有多大？

5. DvD 将视觉和 LLM 分到不同 GPU 上。在什么流量模式下 DvD 会降低而非提升吞吐量？

## 关键术语

| 术语 | 通俗说法 | 准确含义 |
|------|----------|----------|
| 原生多模态预训练（Native multimodal pretraining） | "一起从头开始" | 文本 + 图像 + 视频 token 从第一步起参与损失，而不是事后拼接。 |
| 对齐债务（Alignment debt） | "事后惩罚" | 将视觉拼接到冻结 LLM 上所带来的文本技能和答案一致性方面的可量化退化。 |
| V2PE | "可变视觉位置编码" | 每模态可学习位置编码分配；InternVL3 的 M-RoPE 后继者。 |
| ViR | "分辨率路由器" | 在编码前选择每次查询所需最低分辨率的小分类器，节省推理 token。 |
| DvD | "解耦部署" | 视觉编码器在一块 GPU 上，LLM 在另一块上，通过流式传输交接；使大型 VLM 吞吐量翻倍。 |
| InternVL-U | "统一理解 + 生成" | 2026 年的后续版本，在原生预训练骨干上添加图像生成头。 |
| 交错语料库（Interleaved corpus） | "OBELICS / MMC4" | 自然阅读顺序中包含文本和图像的文档；原生预训练的原材料。 |
