# LLaVA-OneVision：单图像、多图像、视频统一到一个模型

> 在 LLaVA-OneVision（Li 等，2024 年 8 月）之前，开放 VLM 世界存在各自分立的谱系：LLaVA-1.5 用于单图像，Mantis 和 VILA 等用于多图像，Video-LLaVA 和 Video-LLaMA 用于视频。每个模型在自己的基准上表现出色，在其他场景上却失败。LLaVA-OneVision 论证了一个统一的课程学习可以训练一个模型在三种场景下全面领先，而涌现出的任务迁移效应（单图像技能迁移到视频，多图像推理迁移到单图像）超越了专家模型之和。方案出人意料地简单：跨场景保持不变的视觉 token 预算，加上从单图像到 OneVision（多图像）再到视频的显式课程。本章解读这一预算、课程和涌现行为。

**类型：** 构建  
**语言：** Python（标准库，token 预算求解器 + 课程规划器）  
**前置知识：** Phase 12 · 05（LLaVA）、Phase 12 · 06（任意分辨率）  
**预计时间：** 约 180 分钟

## 学习目标

- 设计一个跨单图像、多图像和视频输入保持不变的视觉 token 预算。
- 安排一个能在不发生灾难性遗忘的情况下将技能从单图像迁移到视频的训练课程顺序。
- 解释为什么在相同参数量下，正确的课程学习使单一模型胜过专家模型集合。
- 说出 LLaVA-OneVision 报告的三个涌现能力：多相机推理、集合标记提示、iPhone 截图智能体。

## 问题所在

图像、多图像和视频对模型各有不同的压力。

单图像需要高分辨率 token（AnyRes，约 2880 个视觉 token）来捕捉 OCR 和精细细节。每样本预算：一张图像，2880 个 token。

多图像需要中等分辨率的多张图像（每张约 576 个 token），使跨图像推理能放入上下文。每样本预算：4-8 张图像，每张 576 个，共 2300-4600 个 token。

视频需要大量低分辨率帧（池化后每帧约 196 个 token）来捕捉时序动态。每样本预算：8-32 帧，每帧 196 个，共 1600-6200 个 token。

训练独立模型时，你只能选一种预算。训练单一模型时，你需要预算能跨场景合理扩展，同时不撑爆上下文。

在 OneVision 之前，默认答案是"训练一个场景，忽略其他场景"。Video-LLaVA 通过额外训练阶段将视频功能嫁接到图像模型上。LLaVA-NeXT 用平铺添加了多图像支持。没有任何一个能干净地处理全部三种场景。

## 核心概念

### OneVision Token 预算

LLaVA-OneVision 选择了统一的视觉 token 预算，每样本约 3000-4000 个 token，不同场景分配方式不同：

- **单图像：** AnyRes-9（3×3 平铺 + 缩略图），每个平铺在 384 分辨率下有 729 个图块，激进双线性池化 2×2 → 每平铺 182 个。总计：9×182 + 182 = 1820 个 token。或 AnyRes-4，每平铺 729 个 = 2916 + 729 个。
- **多图像：** 每张图像中等分辨率（384，不平铺），无池化 729 个 token。6 张图像预算 → 4374 个 token。
- **视频：** 32 帧，384 分辨率，激进 3×3 双线性池化 → 每帧 81 个 token。总计：32×81 = 2592 个 token。

分配保持总 token 数大致不变。LLM 看到的批次永远不会撑爆上下文。编码器每个场景产生不同的几何形状，但 LLM 消耗相同的预算。

### 三阶段课程

LLaVA-OneVision 分三个阶段训练：

1. **单图像 SFT（阶段 SI）。** 所有数据都是单图像加文本。在高分辨率 AnyRes 输入上训练。训练感知、OCR 和细粒度理解。使用 LLaVA-NeXT 数据加 OneVision 专属单图像数据。
2. **OneVision SFT（阶段 OV）。** 混合单图像 + 多图像 + 视频（均匀采样帧）。在统一 token 预算上训练。训练模型处理异质批次形状。不重置权重——从阶段 SI 继续。
3. **任务迁移（阶段 TT）。** 使用目标任务混合继续训练，通常根据产品加重多图像或视频权重。部署前的可选微调。

关键：课程顺序很重要。视频优先或多图像优先训练产生的图像性能比单图像优先差，即使使用相同数据。论文明确地消融了这一点。

### 为什么课程有效

单图像训练建立感知基础。图块 token 携带细粒度视觉特征；LLM 学会将其与文本整合。多图像和视频引入了结构性挑战（哪张图像是哪个、什么先发生），这些挑战在没有强感知基础的情况下很难学习。

如果从头同时训练所有场景，模型会对感知欠拟合（每批次单图像数据有限），对结构过拟合（大量多图像/视频数据）。结果：一个遵循跨图像推理模式但视觉浅薄的模型。

课程顺序让你从阶段 SI 获得感知强度，然后从阶段 OV 获得组合性/时序推理，而不失去任何一个。

### 跨场景涌现技能

LLaVA-OneVision 论文报告了三个涌现能力：

1. **多相机推理。** 在多图像 + 视频上分别训练；推理时被要求对多相机驾驶场景进行推理。模型正确整合了各个视角，尽管从未在训练中见过那种确切格式。
2. **集合标记提示。** 用户用编号标记在图像中注释对象；模型推理"标记 3 相对于标记 7 在做什么"。既没有在标记上也没有在注释上训练；从空间定位 + 多图像参考的组合中学会。
3. **iPhone 截图智能体。** 用户提供 iPhone 屏幕截图并要求规划下一次点击。在 UI 截图、用户工作流视频和多图像前后对上训练。泛化到智能体用例。

这些不是训练任务；它们从课程的组合结构中涌现。

### 视觉 Token 池化

Token 预算需要池化。OneVision 在二维图块网格上使用双线性插值：24×24 = 576 个图块变成 12×12 = 144 个（2 倍因子）或 8×8 = 64 个（3 倍因子）。池化在图块网格空间中完成，而非 token 空间，以保留局部性。

每个场景池化因子的选择本身是一个超参数。较少池化 = 更多 token = 更丰富的表示。较多池化 = 更少 token = 可以放入更多帧/图像。

### LLaVA-OneVision-1.5

2025 年的后续（LLaVA-OneVision-1.5，arXiv 2509.23661）在训练数据、模型权重和代码上"完全开放"。在某些基准上弥合了与专有模型的差距，使方案民主化。相同课程，更多数据，更好的基础 LLM，无架构变化。

### 与 Qwen2.5-VL 的对比

Qwen2.5-VL（Lesson 12.09）做了不同的选择：使用 M-RoPE 和动态 FPS，而不是固定池化。其预算随输入扩展——1 分钟视频使用比 5 秒视频更多的 token。LLaVA-OneVision 固定预算并扩展池化。两者都有效；它们在可配置性和可预测性之间进行权衡。

## 动手使用

`code/main.py` 是 OneVision 风格 VLM 的课程和预算规划器。给定每样本 token 预算和目标场景混合（比如 40% 单图像、30% 多图像、30% 视频），它：

- 为每个场景分配分辨率、池化因子和帧数。
- 检查每个场景都能放入共享预算。
- 报告预期 token 数、LLM FLOPs 以及哪些场景 token 不足。
- 打印逐阶段训练计划。

用它规划 OneVision 微调，或对 VLM 部署的每请求成本进行健全性检查。

## 输出产物

本章生成 `outputs/skill-onevision-budget-planner.md`。给定目标任务分布和每样本预算，它输出 AnyRes 因子、每帧池化、视频帧数和课程阶段权重。每次训练或微调统一场景 VLM 时使用。

## 练习

1. 你的产品支持 80% 单图像、10% 多图像（2-4 张）、10% 视频（8-16 帧）。设计 token 预算。你会把不做大量多图像节省下来的额外预算分配到哪里？

2. 阅读 LLaVA-OneVision 第 4.3 节（涌现能力）。提出课程可能解锁但论文未报告的第四个涌现技能。

3. 调换课程顺序——先训练多图像，然后单图像，然后视频。预测哪些基准会退化，为什么。

4. 论文报告视频基准每样本只训练 8 帧。这能泛化到推理时 30 秒的视频吗？什么先崩溃——token 预算还是时序推理？

5. 24×24 图块到 12×12 的双线性池化是每维度 4 倍缩减。用标准库 Python 实现池化，并验证每个 2×2 块的均值与双线性输出一致。

## 关键术语

| 术语 | 通俗说法 | 准确含义 |
|------|----------|----------|
| OneVision 场景 | "单图像、多图像或视频" | 统一 VLM 处理的三种输入形状之一；预算在三者间保持不变。 |
| Token 预算（Token budget） | "每样本多少 token" | LLM 每次训练/推理样本看到的视觉 token 总数，通常为 3000-4000 个。 |
| 课程（Curriculum） | "训练顺序" | 为涌现迁移选择的阶段顺序（单图像 → 多图像 → 视频）。 |
| 双线性池化（Bilinear pooling） | "Token 缩减" | 对图块网格（二维）应用双线性插值以减少 token 数，同时保留局部性。 |
| 涌现技能（Emergent skill） | "未训练但有效" | 由于课程组合而在推理时出现的能力，没有匹配的训练数据。 |
| AnyRes-k | "k 平铺设置" | k 个固定分辨率的子平铺加一张缩略图，典型 k ∈ {4, 9}。 |
| 任务迁移（Task transfer） | "跨场景泛化" | 在单图像上学到的技能通过共享骨干应用到视频（及反之）。 |
