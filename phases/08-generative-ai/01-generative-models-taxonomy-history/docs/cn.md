# 生成模型——分类与历史

> 每一个图像模型、文本模型、视频模型、3D 模型，都归属于这五个桶中的一个。选错了桶，你会跟数学搏斗好几周。选对了，过去十二年的研究进展就会在你脑海中清晰排列。

**类型：** 学习
**语言：** Python
**前置知识：** 第2阶段（机器学习基础）、第3阶段（深度学习核心）、第7阶段第14课（Transformer）
**预计时间：** 约45分钟

## 问题背景

生成模型只做一件事：给定从某个未知分布 `p_data(x)` 采样的训练样本，输出看起来像来自同一分布的新样本。人脸、句子、MIDI 文件、蛋白质结构——只要你眯起眼睛，都是同一个问题。

难点在于 `p_data` 生活在一个有数百万维的空间里（一张 512×512 的 RGB 图像约有 78.6 万维），样本只落在这个空间中的一个薄薄的流形上，而你可能只有 1000 万个样本。暴力估计密度完全没有希望。每一个生成模型都是一种妥协——用一个困难问题换一个稍微没那么难的问题。

在过去十二年里，五个家族存活了下来。了解每个家族做出了哪种妥协，就能明白为什么它在某些任务上胜出，在另一些任务上失败。

## 核心概念

![生成模型的五个家族——按建模对象分类的分类图](../assets/taxonomy.svg)

**1. 显式密度，可精确计算。** 将 `log p(x)` 写成一个可以实际求值的求和式。自回归模型（PixelCNN、WaveNet、GPT）将 `p(x) = ∏ p(x_i | x_<i)` 分解。归一化流（RealNVP、Glow）将 `p(x)` 构建为简单基础分布的可逆变换。优点：精确似然，训练损失干净。缺点：自回归推理是串行的（长序列很慢），流需要可逆架构（架构受限）。

**2. 显式密度，近似计算。** 从下方界定 `log p(x)`（ELBO），优化这个下界。VAE（Kingma 2013）使用带变分后验的编码器-解码器结构。扩散模型（DDPM，Ho 2020）训练一个去噪器，隐式优化加权 ELBO。扩散模型是 2026 年图像、视频、3D 的主流骨干。

**3. 隐式密度。** 完全绕过密度估计；学习一个生成器 `G(z)`（产生样本）和一个判别器 `D(x)`（区分真假）。即 GAN（Goodfellow 2014）。推理速度快（单次前向传播），但训练时出了名的不稳定。StyleGAN 1/2/3 在固定领域的照片级真实感（人脸、卧室）上，哪怕到 2026 年仍是业界标杆。

**4. 分数匹配 / 连续时间。** 直接学习对数密度的梯度 `∇_x log p(x)`（即"分数"）。Song & Ermon（2019）证明分数匹配可以将扩散推广为随机微分方程（SDE）。流匹配（Flow matching，Lipman 2023）是 2024—2026 年的热点：免模拟训练、路径更直、采样速度比 DDPM 快 4—10 倍。Stable Diffusion 3、Flux、AudioCraft 2 均使用流匹配。

**5. 离散码上的基于 token 的自回归。** 用 VQ-VAE 或残差量化器将高维数据压缩成短序列的离散 token，再用 Transformer 对 token 序列建模。Parti、MuseNet、AudioLM、VALL-E、Sora 的 patch tokenizer 都属于这一类。这相当于第一类加上一个学习型分词器。

| 2014 | GAN（Goodfellow） | 隐式密度，无需似然——样本质量出人意料地清晰。 |

| 2020 | DDPM（Ho） | 扩散模型走向实用。 |
| 2021 | CLIP、DALL-E 1、VQGAN | 文生图步入主流。 |

## 五问分类法

每当一篇新的生成模型论文发布，在阅读方法部分之前，先回答这五个问题。

1. **建模对象是什么？** 像素、潜变量、离散 token、3D 高斯、网格、波形？
2. **密度是显式还是隐式的？** 他们有没有写出 `log p(x)`？
3. **采样：一次性还是迭代式？** 迭代意味着推理较慢；一次性通常意味着对抗训练或蒸馏。
4. **条件：无条件、类别、文本、图像、姿态？** 这决定了损失函数和架构支撑。
5. **评估指标：FID、CLIP 得分、IS、人类偏好、任务准确率？** 每种指标都有已知的失效模式（见第14课）。

你将在本阶段的每节课中重复回答这五个问题。到最后，它们会成为你的本能反应。

## 动手实现

本课的代码是一个轻量级可视化：用三种玩具方法（核密度估计、离散直方图、最近邻"GAN 风格"生成器）从样本中拟合一维高斯混合分布，让你在一屏之内看清显式密度与隐式密度的区别。

运行 `code/main.py`。它从两峰高斯混合分布中抽取 2000 个样本，然后打印：

```
explicit density (histogram): p(x in [-0.5, 0.5]) ≈ 0.38
approximate density (KDE):     p(x in [-0.5, 0.5]) ≈ 0.41
implicit (nearest-sample gen): 20 new samples printed, no p(x)
```

注意：前两种方法让你可以问"这个点有多大可能？"第三种方法做不到这一点。这就是**显式密度 vs 隐式密度**的区别，它在之后每一节课中都会重要。

## 工程应用

2026 年，哪个任务用哪个家族？

| 任务 | 最佳家族 | 原因 |
|------|---------|------|
| 照片级真实感人脸、窄领域 | StyleGAN 2/3 | 仍然最清晰、推理最快。 |
| 通用文生图 | 潜在扩散 + 流匹配 | SD3、Flux.1、DALL-E 3。 |
| 快速文生图 | 整流流 + 蒸馏 | SDXL-Turbo、SD3-Turbo、LCM。 |
| 文生视频 | 扩散 Transformer + 流匹配 | Sora、Veo 2、Kling。 |
| 语音 + 音乐 | 基于 token 的自回归（AudioLM、VALL-E、MusicGen）或流匹配（AudioCraft 2） | 离散 token 扩展成本低。 |
| 3D 场景 | 高斯溅射拟合、扩散先验 | 3D-GS 用于重建，扩散用于新视角合成。 |
| 密度估计（不需要采样） | 归一化流 | 唯一能提供精确 `log p(x)` 的家族。 |
| 仿真 / 物理 | 流匹配、分数 SDE | 路径更直、向量场更平滑。 |

## 关键术语

| 术语 | 常见说法 | 真正含义 |
|------|---------|---------|
| 生成模型 (Generative model) | "它能生成新东西" | 学习 `p_data(x)` 的采样器，可选地暴露 `log p(x)`。 |
| 显式密度 (Explicit density) | "可以求值" | 模型提供封闭形式或可计算的 `log p(x)`。 |
| 隐式密度 (Implicit density) | "GAN 风格" | 只有采样器——无法对给定点求 `p(x)`。 |
| ELBO | "证据下界" | `log p(x)` 的可计算下界；VAE 和扩散模型优化它。 |
| 分数 (Score) | "对数密度的梯度" | `∇_x log p(x)`；扩散和 SDE 模型学习这个向量场。 |
| 流形假设 (Manifold hypothesis) | "数据落在一个曲面上" | 高维数据集中在低维流形上；这就是为什么降维有效。 |
| 自回归 (Autoregressive) | "预测下一个片段" | 将联合分布分解为条件分布之积。 |
| 潜变量 (Latent) | "压缩编码" | 低维表示，解码器可从中重建输入。 |

## 生产说明：五个家族，五种推理开销曲线

每个家族对应不同的推理服务成本曲线。生产推理文献将 LLM 推理分解为预填充（prefill）+ 解码（decode）；相同的分解方式也适用于这里：

- **自回归（第1类和第5类）。** 串行解码主导延迟；KV 缓存、连续批处理和投机解码均可直接适用。
- **VAE / 扩散 / 流匹配（第2类和第4类）。** 没有 LLM 意义上的解码。成本 = `步数 × 单步成本`，而 `单步成本` 是一次完整潜在分辨率上的 Transformer 或 U-Net 前向传播。生产旋钮是步数（DDIM / DPM-Solver / 蒸馏）、批大小和精度（bf16 / fp8 / int4）。
- **GAN（第3类）。** 单次前向传播。没有调度，没有 KV 缓存。首 token 时间 ≈ 总延迟。这就是为什么 StyleGAN 在窄领域用户体验上仍然胜出。

当你在论文摘要中看到"比扩散更快"，请将其翻译为"步数更少 × 单步成本相同"或"步数相同 × 单步成本更低"。其他说法都是营销话术。
