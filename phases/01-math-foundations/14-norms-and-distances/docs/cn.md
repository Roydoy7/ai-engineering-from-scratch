# 范数与距离

> 你的距离函数定义了"相似"的含义。选错了，下游的一切都会出错。

**类型：** 构建实现
**语言：** Python
**前置知识：** 第一阶段，第01课（线性代数直觉）、第02课（向量、矩阵与运算）
**时间：** 约90分钟

## 学习目标

- 从零实现L1、L2、余弦、马哈拉诺比斯（Mahalanobis）、Jaccard和编辑距离函数
- 为给定的ML任务选择合适的距离度量，并解释为什么其他选择会失败
- 将L1和L2范数与LASSO和岭回归正则化及其几何约束区域联系起来
- 证明同一数据集在不同度量下会产生不同的最近邻

## 问题背景

你有两个向量。也许是词嵌入，也许是用户画像，也许是像素数组。你需要知道：它们有多接近？

答案完全取决于你选择哪种距离函数。两个数据点在一种度量下可能是最近邻，在另一种度量下可能相距甚远。你的KNN分类器、推荐引擎、向量数据库、聚类算法、损失函数——全都依赖这个选择。选错了，你的模型就在为错误的事情优化。

**没有通用最优距离。** L2适用于空间数据，余弦相似度在NLP中占主导，Jaccard处理集合，编辑距离处理字符串，马哈拉诺比斯考虑相关性，Wasserstein移动概率质量。每种都编码了关于"相似"含义的不同假设。

## 核心概念

### 范数：测量向量大小

范数测量向量的"大小"。两个向量之间的每种距离函数都可以写成其差向量的范数：d(a, b) = ||a - b||。理解范数就是理解距离。

### L1范数（曼哈顿距离）

L1范数是所有分量绝对值之和。

```
||x||_1 = |x_1| + |x_2| + ... + |x_n|
```

之所以叫曼哈顿距离，是因为它衡量的是在只能沿轴线（不能走对角线）移动的城市网格上走多远。

```
点A = (1, 1)
点B = (4, 5)

L1距离 = |4-1| + |5-1| = 3 + 4 = 7

在网格上，你向东走3个街区，向北走4个街区。
```

何时使用L1：
- 高维稀疏数据（文本特征、独热编码）
- 需要对异常值鲁棒时（单个巨大差异不会主导结果）
- 特征选择问题（L1正则化促进稀疏性）

与L1正则化（Lasso）的联系：将||w||_1加入损失函数会惩罚权重绝对值之和。这会将小权重推向精确的零，执行自动特征选择。L1惩罚在权重空间中创建菱形约束区域，菱形的角位于轴线上，某些权重在那里为零。

与损失函数的联系：平均绝对误差（MAE）是预测值与目标值之间的平均L1距离。它对所有误差进行线性惩罚，使其相对于MSE对异常值更鲁棒。

### L2范数（欧几里得距离）

L2范数是直线距离，即各分量平方和的平方根。

```
||x||_2 = sqrt(x_1^2 + x_2^2 + ... + x_n^2)
```

这是你在几何课上学过的距离，n维空间中的勾股定理。

```
点A = (1, 1)
点B = (4, 5)

L2距离 = sqrt((4-1)^2 + (5-1)^2) = sqrt(9 + 16) = sqrt(25) = 5.0

穿过网格的直线斜线。
```

何时使用L2：
- 低到中维度的连续数据
- 特征尺度相当时
- 物理距离（空间数据、传感器读数）
- 像素级图像相似度

与L2正则化（Ridge）的联系：将||w||_2^2加入损失函数会惩罚大权重。与L1不同，它不会将权重推向零。而是按比例将所有权重向零收缩。L2惩罚创建圆形约束区域，轴线上没有角点，权重会变小但很少精确为零。

与损失函数的联系：均方误差（MSE）是L2距离的平方的平均值，平方使大误差比小误差受到更重的惩罚。

```
MAE（L1损失）:  |y - y_hat|         线性惩罚。对异常值鲁棒。
MSE（L2损失）:  (y - y_hat)^2       二次惩罚。对异常值敏感。
```

### Lp范数：通用族

L1和L2是Lp范数的特例：

```
||x||_p = (|x_1|^p + |x_2|^p + ... + |x_n|^p)^(1/p)
```

不同的p值产生不同形状的"单位球"（到原点距离为1的所有点的集合）：

```
p=1:    菱形        （角在坐标轴上）
p=2:    圆/球       （通常的圆球）
p=3:    超椭圆      （圆角矩形）
p=inf:  正方形/超立方体  （沿坐标轴的平边）
```

### L无穷范数（切比雪夫距离）

当p趋向无穷时，Lp范数收敛到最大绝对分量值。

```
||x||_inf = max(|x_1|, |x_2|, ..., |x_n|)
```

两点之间的距离由它们差异最大的单一维度决定，所有其他维度被忽略。

```
点A = (1, 1)
点B = (4, 5)

L无穷距离 = max(|4-1|, |5-1|) = max(3, 4) = 4
```

何时使用L无穷：
- 当任何单一维度中的最坏偏差很重要时
- 棋盘游戏（国际象棋中国王按L无穷移动：向任意方向一步代价为1）
- 制造公差（每个维度都必须在规格范围内）

### 余弦相似度与余弦距离

余弦相似度测量两个向量之间的角度，忽略它们的大小。

```
cos_sim(a, b) = (a · b) / (||a||_2 * ||b||_2)
```

范围从-1（方向相反）到+1（方向相同）。垂直向量的余弦相似度为0。

余弦距离将其转换为距离：cosine_distance = 1 - cosine_similarity，范围从0（相同方向）到2（相反方向）。

```
a = (1, 0)    b = (1, 1)

cos_sim = (1*1 + 0*1) / (1 * sqrt(2)) = 1/sqrt(2) = 0.707
cos_dist = 1 - 0.707 = 0.293
```

余弦相似度在NLP和嵌入领域主导的原因：在文本中，文档长度不应影响相似度。一篇关于猫的文档如果是另一篇关于猫的文档的两倍长，仍然应该"相似"。余弦相似度忽略大小（长度），只关心方向。两篇词语分布相同但长度不同的文档指向同一方向，余弦相似度为1.0。

何时使用余弦相似度：
- 文本相似度（TF-IDF向量、词嵌入、句子嵌入）
- 大小是噪声而方向是信号的任何领域
- 推荐系统（用户偏好向量）
- 嵌入搜索（向量数据库几乎总是使用余弦或点积）

### 点积相似度 vs 余弦相似度

两个向量的点积是：

```
a · b = a_1*b_1 + a_2*b_2 + ... + a_n*b_n
      = ||a|| * ||b|| * cos(角度)
```

余弦相似度是点积除以两个向量大小的归一化版本。当两个向量都已经是单位归一化（大小=1）时，点积和余弦相似度相同。

```
若 ||a|| = 1 且 ||b|| = 1:
    a · b = cos(a和b之间的角度)
```

区别在于：点积包含大小信息。大小更大的向量得到更高的点积分数。这在某些你希望"受欢迎"的项目排名更高的检索系统中很重要，大小作为隐式质量或重要性信号。

```
a = (3, 0)    b = (1, 0)    c = (0, 1)

dot(a, b) = 3     dot(a, c) = 0
cos(a, b) = 1.0   cos(a, c) = 0.0

两者在方向上一致，但点积也反映大小。
```

实践中：
- 当你想要纯粹的方向相似度时使用余弦相似度
- 当大小携带有意义的信息时使用点积
- 许多向量数据库（Pinecone、Weaviate、Qdrant）让你在两者间选择
- 如果你的嵌入是L2归一化的，选择哪个无所谓

### 马哈拉诺比斯距离

欧几里得距离对所有维度一视同仁，但如果你的特征相关联或具有不同的尺度，L2会给出误导性的结果。

马哈拉诺比斯距离考虑数据的协方差结构。

```
d_M(x, y) = sqrt((x - y)^T * S^(-1) * (x - y))
```

其中S是数据的协方差矩阵。

直觉上：马哈拉诺比斯距离首先去相关并归一化数据（白化），然后在变换后的空间中计算L2距离。如果S是单位矩阵（不相关、单位方差特征），马哈拉诺比斯距离退化为欧几里得距离。

```
示例：身高和体重是相关的。
身高6'2"、体重180磅的人并不罕见。
身高5'0"、体重180磅的人则不寻常。

欧几里得距离可能说它们与均值等距。
马哈拉诺比斯距离能正确识别第二个为异常值，
因为它考虑了身高-体重的相关性。
```

何时使用马哈拉诺比斯距离：
- 异常检测（马哈拉诺比斯距离大的点是离群点）
- 特征具有不同尺度和相关性时的分类
- 有足够数据估计可靠协方差矩阵时
- 制造业质量控制（多元过程监控）

### Jaccard相似度（用于集合）

Jaccard相似度测量两个集合之间的重叠程度。

```
J(A, B) = |A ∩ B| / |A ∪ B|
```

范围从0（无重叠）到1（完全相同的集合）。Jaccard距离 = 1 - Jaccard相似度。

```
A = {猫, 狗, 鱼}
B = {猫, 鸟, 鱼, 蛇}

交集 = {猫, 鱼}         大小 = 2
并集 = {猫, 狗, 鱼, 鸟, 蛇}  大小 = 5

Jaccard相似度 = 2/5 = 0.4
Jaccard距离 = 0.6
```

何时使用Jaccard：
- 比较标签、类别或特征的集合
- 基于词语出现（非频率）的文档相似度
- 近似重复检测（Jaccard的MinHash近似）
- 比较二元特征向量（存在/不存在数据）
- 评估分割模型（交并比=Jaccard）

### 编辑距离（Levenshtein距离）

编辑距离计算将一个字符串转换为另一个字符串所需的最少单字符操作数。操作包括：插入、删除或替换。

```
"kitten" -> "sitting"

kitten -> sitten  （替换 k -> s）
sitten -> sittin  （替换 e -> i）
sittin -> sitting （插入 g）

编辑距离 = 3
```

使用动态规划计算。填充一个矩阵，其中条目(i, j)是字符串A的前i个字符与字符串B的前j个字符之间的编辑距离。

```
        ""  s  i  t  t  i  n  g
    ""   0  1  2  3  4  5  6  7
    k    1  1  2  3  4  5  6  7
    i    2  2  1  2  3  4  5  6
    t    3  3  2  1  2  3  4  5
    t    4  4  3  2  1  2  3  4
    e    5  5  4  3  2  2  3  4
    n    6  6  5  4  3  3  2  3
```

何时使用编辑距离：
- 拼写检查和纠错
- DNA序列比对（带加权操作）
- 模糊字符串匹配
- 杂乱文本数据去重

### KL散度（不是距离，但被当作距离用）

KL散度测量一个概率分布与另一个的差异。在第09课中介绍过，但它属于这里的讨论，因为人们将它当作"距离"使用，尽管它实际上不是。

```
D_KL(P || Q) = sum(p(x) * log(p(x) / q(x)))
```

关键特性：KL散度**不是**对称的。

```
D_KL(P || Q) != D_KL(Q || P)
```

这意味着它不满足距离度量的基本要求，也不满足三角不等式。它是散度（divergence），不是距离（distance）。

正向KL（D_KL(P || Q)）是"均值寻找"的：Q尝试覆盖P的所有模式。
反向KL（D_KL(Q || P)）是"模式寻找"的：Q聚焦于P的单一模式。

KL散度出现的场合：
- VAE（ELBO中的KL项将潜在分布推向先验分布）
- 知识蒸馏（学生尝试匹配教师的分布）
- RLHF（KL惩罚使微调模型保持接近基础模型）
- 策略梯度方法（约束策略更新）

### Wasserstein距离（推土机距离）

Wasserstein距离测量将一个概率分布转换为另一个所需的最小"工作量"。可以这样理解：如果一个分布是一堆土，另一个是一个坑，需要移动多少土，移动多远？

```
W(P, Q) = 对所有运输方案gamma的 E[d(x, y)] 的下确界
```

对于一维分布，它简化为累积分布函数绝对差的积分：

```
W_1(P, Q) = ∫ |CDF_P(x) - CDF_Q(x)| dx
```

Wasserstein重要的原因：
- 它是真正的度量（对称的，满足三角不等式）
- 即使分布不重叠也能提供梯度（KL散度会趋向无穷大）
- 这一特性使其成为Wasserstein GAN（WGAN）的核心，解决了原始GAN的训练不稳定性

```
无重叠的分布：

P: [1, 0, 0, 0, 0]    Q: [0, 0, 0, 0, 1]

KL散度: 无穷大（零的对数）
Wasserstein: 4（移动所有质量4个箱子）

Wasserstein给出有意义的梯度，KL散度做不到。
```

何时使用Wasserstein：
- GAN训练（WGAN、WGAN-GP）
- 比较可能不重叠的分布
- 最优传输问题
- 图像检索（比较颜色直方图）

### 为什么不同任务需要不同距离

| 任务 | 最佳距离 | 原因 |
|------|---------|------|
| 文本相似度 | 余弦 | 大小是噪声，方向是含义 |
| 图像像素比较 | L2 | 空间关系重要，特征尺度相当 |
| 稀疏高维特征 | L1 | 鲁棒，不放大罕见的大差异 |
| 集合重叠（标签、类别） | Jaccard | 数据本质上是集合值，不是向量 |
| 字符串匹配 | 编辑距离 | 操作与人类编辑直觉对应 |
| 异常检测 | 马哈拉诺比斯 | 考虑特征相关性和尺度 |
| 比较分布 | KL散度 | 测量用Q代替P损失的信息 |
| GAN训练 | Wasserstein | 即使分布不重叠也提供梯度 |
| 嵌入（向量数据库） | 余弦或点积 | 嵌入被训练为在方向中编码含义 |
| 推荐系统 | 点积 | 大小可以编码流行度或置信度 |
| DNA序列 | 加权编辑距离 | 替换代价随核苷酸对变化 |
| 制造业质量控制 | L无穷 | 任何维度的最坏偏差很重要 |

### 与损失函数的联系

损失函数是应用于预测值与目标值之间的距离函数。

```
损失函数           使用的距离              行为
MSE              L2平方              对大误差惩罚更重
MAE              L1                  对所有误差等量惩罚
Huber损失         大误差用L1,          两者兼顾：对异常值鲁棒，
                  小误差用L2          零附近梯度平滑
交叉熵            KL散度              测量分布不匹配
Hinge损失         max(0, margin - d)  只惩罚低于边距的情况
三元组损失（Triplet）L2（通常）          将正样本拉近，将
                                      负样本推远
对比损失          L2                  相似对靠近，不相似
                                      对超过边距
```

### 与正则化的联系

正则化向损失函数添加权重的范数惩罚。

```
L1正则化（Lasso）:   损失 + lambda * ||w||_1
  -> 稀疏权重。某些权重变成精确的零。
  -> 自动特征选择。
  -> 解在零处有角点（不可微）。

L2正则化（Ridge）:   损失 + lambda * ||w||_2^2
  -> 小权重。所有权重向零收缩。
  -> 无特征选择（没有精确为零）。
  -> 处处平滑的解。

弹性网络（Elastic Net）: 损失 + lambda_1 * ||w||_1 + lambda_2 * ||w||_2^2
  -> 结合L1的稀疏性和L2的稳定性。
  -> 相关特征组被一起保留或丢弃。
```

为什么L1产生稀疏性而L2不会：在2D权重空间中画出约束区域。L1是菱形，L2是圆形。损失函数的等高线（椭圆）最可能在菱形的角点处与其相切，那里某个权重为零。它们在圆形上的光滑点处相切，两个权重都不为零。

### 最近邻搜索

每种距离函数都隐含一个最近邻搜索问题：给定查询点，找到数据集中最接近的点。

精确最近邻搜索在n个点d维数据集中每次查询为O(n * d)。对于大数据集，这太慢了。

近似最近邻（ANN）算法以少量精度换取巨大的速度提升：

```
算法          方法                          使用者
KD树          轴对齐空间分区                scikit-learn（低维）
球树          嵌套超球体                    scikit-learn（中维）
LSH           随机哈希投影                  近似重复检测
HNSW          层次可导航小世界图            FAISS、Qdrant、Weaviate
IVF           带簇搜索的倒排文件索引        FAISS（十亿规模）
产品量化       压缩向量，在压缩空间搜索      FAISS（内存受限）
```

HNSW（层次可导航小世界）是现代向量数据库中的主流算法。它构建一个多层图，每个节点连接到其近似最近邻。搜索从顶层（稀疏，长跳）开始，下降到底层（密集，短跳）。

## 应用示例

最常见的实际应用：在向量数据库中查找相似项目。

```python
import numpy as np

def cosine_similarity_matrix(X):
    norms = np.linalg.norm(X, axis=1, keepdims=True)
    norms = np.where(norms == 0, 1, norms)
    X_normalized = X / norms
    return X_normalized @ X_normalized.T

embeddings = np.random.randn(1000, 768)

sim_matrix = cosine_similarity_matrix(embeddings)

query_idx = 0
similarities = sim_matrix[query_idx]
top_k = np.argsort(similarities)[::-1][1:6]
print(f"与第0项最相似的前5项: {top_k}")
print(f"相似度: {similarities[top_k]}")
```

当你调用`model.encode(text)`然后搜索向量数据库时，底层就是这样工作的。嵌入模型将文本映射到向量。向量数据库计算你的查询向量与每个存储向量之间的余弦相似度（或点积），使用ANN算法避免检查所有向量。

## 关键术语

| 术语 | 通俗说法 | 实际含义 |
|------|---------|---------|
| 范数（Norm） | "向量的大小" | 将向量映射到非负标量的函数，满足三角不等式、绝对齐次性，且只有零向量映射到零 |
| L1范数 | "曼哈顿距离" | 绝对分量值之和。在优化中产生稀疏性。对异常值鲁棒 |
| L2范数 | "欧几里得距离" | 分量平方和的平方根。欧几里得空间中的直线距离 |
| Lp范数 | "广义范数" | 绝对分量p次方之和的p次方根。L1和L2是特例 |
| L无穷范数 | "最大范数"或"切比雪夫距离" | 最大绝对分量值。p趋向无穷时Lp的极限 |
| 余弦相似度（Cosine similarity） | "向量间的角度" | 点积除以两个大小的乘积。范围从-1到+1。忽略向量长度 |
| 余弦距离（Cosine distance） | "1减余弦相似度" | 将余弦相似度转换为距离。范围从0到2 |
| 点积（Dot product） | "未归一化的余弦" | 分量乘积之和。等于余弦相似度乘以两个大小 |
| 马哈拉诺比斯距离（Mahalanobis distance） | "考虑相关性的距离" | 在用数据协方差矩阵白化（去相关和归一化）的空间中的L2距离 |
| Jaccard相似度 | "集合重叠" | 交集大小除以并集大小。适用于集合，不适用于向量 |
| 编辑距离（Edit distance） | "Levenshtein距离" | 将一个字符串转换为另一个所需的最少插入、删除和替换操作数 |
| KL散度（KL divergence） | "分布间的距离" | 不是真正的距离（不对称）。测量用Q编码P多用的比特数 |
| Wasserstein距离 | "推土机距离" | 将质量从一个分布传输到另一个的最小工作量。是真正的度量 |
| 近似最近邻（ANN） | "ANN搜索" | 找到近似最近点的算法（HNSW、LSH、IVF），比精确搜索快得多 |
| HNSW | "向量数据库算法" | 层次可导航小世界图。用于快速近似最近邻搜索的多层图 |
| L1正则化 | "Lasso" | 将权重的L1范数加入损失。将权重推向零（稀疏性） |
| L2正则化 | "Ridge"或"权重衰减" | 将权重L2范数的平方加入损失。使权重向零收缩但无稀疏性 |
| 弹性网络（Elastic Net） | "L1 + L2" | 结合L1和L2正则化。比单独使用任一种更好地处理相关特征组 |
