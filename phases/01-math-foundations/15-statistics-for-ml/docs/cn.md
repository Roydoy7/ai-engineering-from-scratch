# 机器学习统计学

> 统计学告诉你你的模型究竟是真的有效，还是只是运气好。

**类型：** 构建实现
**语言：** Python
**前置知识：** 第一阶段，第06课（概率与分布）、第07课（贝叶斯定理）
**时间：** 约120分钟

## 学习目标

- 从零计算描述性统计量、Pearson/Spearman相关性和协方差矩阵
- 执行假设检验（t检验、卡方检验），并正确解释p值和置信区间
- 使用自助法（bootstrap）为任意指标构建置信区间，无需分布假设
- 使用效应量指标区分统计显著性与实际显著性

## 问题背景

你训练了两个模型。模型A在测试集上得分0.87，模型B得分0.89。你部署了模型B。三周后，生产指标比以前更差。发生了什么？

模型B实际上并没有超过模型A。0.02的差异是噪声。你的测试集太小，或者方差太高，或者两者兼有。你把随机性当成了改进发布出去。

**这种情况一直在发生：** Kaggle排行榜的混乱、无法复现的论文、基于几百个样本宣布获胜者的A/B测试。根本原因总是相同的：有人跳过了统计。

统计学给你提供区分信号与噪声的工具。它告诉你何时差异是真实的、你应该有多大把握，以及在信任结果之前需要多少数据。每个ML流水线、每次模型比较、每个实验都需要统计。没有它，你只是在猜测。

## 核心概念

### 描述性统计：汇总你的数据

在建模之前，你需要了解数据的样貌。描述性统计将数据集压缩为几个能捕获其形状的数字。

**集中趋势的测量** 回答"中心在哪里？"

```
均值（Mean）:   所有值之和 / 计数
               mu = (1/n) * sum(x_i)

中位数（Median）: 排序后的中间值
               对异常值鲁棒。若有[1, 2, 3, 4, 1000]，均值是202，
               但中位数是3。

众数（Mode）:   最频繁出现的值
               对分类数据有用。对连续数据，通常没有参考价值。
```

均值是平衡点，中位数是中间标记。当两者分离时，你的分布是偏斜的。收入分布均值>>中位数（右偏，来自亿万富翁）。训练中的损失分布通常均值<<中位数（左偏，来自简单样本）。

**离散程度的测量** 回答"数据有多分散？"

```
方差（Variance）: 与均值的平均平方偏差
                 sigma^2 = (1/n) * sum((x_i - mu)^2)

标准差（Std dev）: 方差的平方根
                 sigma = sqrt(sigma^2)
                 与数据同单位，更易解释。

极差（Range）:   最大值 - 最小值
                对异常值敏感。单独使用几乎无用。

IQR（四分位距）: Q3 - Q1（四分位数距离）
                中间50%数据的范围。
                对异常值鲁棒，用于箱形图和异常值检测。
```

**百分位数** 将排序数据分为100等份。第25百分位数（Q1）表示25%的值低于此点。第50百分位数是中位数，第75百分位数是Q3。

```
对延迟监控而言：
  P50 = 中位延迟        （典型用户体验）
  P95 = 第95百分位      （差但不是最坏情况）
  P99 = 第99百分位      （尾部延迟，通常是中位数的10倍）
```

在ML中，你关心推理延迟、预测置信度分布和误差分布的百分位数。平均误差低但P99误差极高的模型在安全关键应用中可能毫无用处。

**样本统计 vs 总体统计。** 从样本计算方差时，用(n-1)代替n，这是贝塞尔校正（Bessel's correction），补偿你的样本均值不是真正总体均值的事实。用n做分母，你会系统性地低估真实方差；用(n-1)，估计是无偏的。

```
总体方差: sigma^2 = (1/N) * sum((x_i - mu)^2)
样本方差: s^2     = (1/(n-1)) * sum((x_i - x_bar)^2)
```

实践中：如果n很大（数千样本），差异可以忽略不计；如果n很小（几十个样本），则很重要。

### 相关性：变量如何共同变化

相关性测量两个变量之间线性关系的强度和方向。

**Pearson相关系数** 测量线性关联：

```
r = sum((x_i - x_bar)(y_i - y_bar)) / (n * s_x * s_y)

r = +1:  完美正线性关系
r = -1:  完美负线性关系
r =  0:  无线性关系（但可能存在非线性关系！）

范围: [-1, 1]
```

Pearson假设关系是线性的，两个变量大致服从正态分布。对异常值敏感，单个极端点可以将r从0.1拖到0.9。

**Spearman秩相关** 测量单调关联：

```
1. 用排名（1, 2, 3, ...）替换每个值
2. 在排名上计算Pearson相关

Spearman能捕获任何单调关系，不只是线性关系。
若y = x^3，Pearson给出r < 1，但Spearman给出rho = 1。
```

**何时使用哪种：**

```
Pearson:    两个变量都是连续的且大致正态。
            你特别关心线性关系。
            无极端异常值。

Spearman:   有序数据（排名、评分）。
            数据不服从正态分布。
            你怀疑是单调但不是线性的关系。
            存在异常值。
```

**黄金法则：相关性不意味着因果关系。** 冰淇淋销售与溺水死亡相关，因为两者在夏季都增加。你的模型准确率和参数数量相关，但增加参数不会自动提高准确率（见：过拟合）。

### 协方差矩阵

两个变量之间的协方差测量它们共同变化的方式：

```
Cov(X, Y) = (1/n) * sum((x_i - x_bar)(y_i - y_bar))

Cov(X, Y) > 0:  X和Y倾向于一起增加
Cov(X, Y) < 0:  当X增加时，Y倾向于减少
Cov(X, Y) = 0:  无线性共动
```

对于d个特征，协方差矩阵C是一个d×d矩阵，其中C[i][j] = Cov(特征_i, 特征_j)。对角元素C[i][i]是每个特征的方差。

```
C = | Var(x1)      Cov(x1,x2)  Cov(x1,x3) |
    | Cov(x2,x1)  Var(x2)      Cov(x2,x3) |
    | Cov(x3,x1)  Cov(x3,x2)  Var(x3)     |

属性：
  - 对称: C[i][j] = C[j][i]
  - 半正定: 所有特征值 >= 0
  - 对角线 = 方差
  - 非对角线 = 协方差
```

**与PCA的联系。** PCA对协方差矩阵进行特征分解。特征向量是主成分（最大方差方向），特征值告诉你每个成分捕获的方差。这正是第10课所讲的，但现在你明白为什么协方差矩阵是正确的分解对象：它编码了数据中所有成对的线性关系。

**与相关性的联系。** 相关矩阵是标准化变量（每个除以其标准差）的协方差矩阵。相关性对协方差进行归一化，使所有值落在[-1, 1]中。

### 假设检验

假设检验是在不确定性下做决策的框架。你从一个声明开始，收集数据，然后确定数据是否与声明一致。

**设置：**

```
零假设（H0）:        默认假设，通常是"无效果"
备择假设（H1）: 你试图证明的内容

示例：
  H0: 模型A和模型B准确率相同
  H1: 模型B准确率高于模型A
```

**p值** 是假设H0为真时，看到与你观测到的数据一样极端的数据的概率。它**不是**H0为真的概率。这是统计学中最常见的误解。

```
p值 = P(数据如此极端 | H0为真)

若 p值 < alpha（通常0.05）:
    拒绝H0。结果"统计显著"。
若 p值 >= alpha:
    未能拒绝H0。你没有足够的证据。
    这不意味着H0为真。
```

**置信区间** 给出参数的合理值范围：

```
均值的95%置信区间：
    x_bar +/- z * (s / sqrt(n))

其中 z = 1.96 对应95%置信度

解释：如果你重复这个实验很多次，95%的计算区间
会包含真实均值。这不是说真实均值有95%的概率
在这个特定区间内。
```

置信区间的宽度告诉你精度。宽区间意味着高不确定性，窄区间意味着你的估计很精确（但如果数据有偏，不一定准确）。

### t检验

t检验比较均值，有几种变体。

**单样本t检验：** 总体均值是否与假设值不同？

```
t = (x_bar - mu_0) / (s / sqrt(n))

自由度 = n - 1
```

**两样本t检验（独立）：** 两组均值是否不同？

```
t = (x_bar_1 - x_bar_2) / sqrt(s1^2/n1 + s2^2/n2)

这是Welch's t检验，不假设等方差。
除非有特定理由假设等方差，否则始终使用Welch's检验。
```

**配对t检验：** 当测量是成对的（同一模型在相同数据划分上评估）时：

```
对每对计算 d_i = x_i - y_i
然后对d_i值针对mu_0 = 0运行单样本t检验
```

在ML中，配对t检验很常见：在相同的10折交叉验证上运行两个模型，然后成对比较它们的分数。

### 卡方检验

卡方检验检查观察频率是否与期望频率匹配。适用于分类数据。

```
chi^2 = sum((观察 - 期望)^2 / 期望)

示例：语言模型的输出分布是否与各类别的训练分布匹配？

类别        观察值    期望值
正面          120       100
负面           80       100
chi^2 = (120-100)^2/100 + (80-100)^2/100 = 4 + 4 = 8

1个自由度，chi^2 = 8，p < 0.005。
差异显著。
```

### ML模型的A/B测试

ML中的A/B测试与网页A/B测试不同。模型比较有特定的挑战：

```
1. 相同测试集:    两个模型必须在相同数据上评估。
                  不同测试集使比较失去意义。

2. 多个指标:      仅准确率不够。需要精确率、召回率、F1、
                  延迟和公平性指标。

3. 方差估计:      使用交叉验证或自助法估计每个指标的
                  方差，不只是点估计。

4. 数据泄漏:      若在模型选择过程中使用了测试集，
                  比较是有偏的。预留最终测试集。
```

**流程：**

```
1. 定义指标和显著性水平（alpha = 0.05）
2. 在相同的k折交叉验证划分上运行两个模型
3. 收集配对分数：[(a1, b1), (a2, b2), ..., (ak, bk)]
4. 计算差异：d_i = b_i - a_i
5. 对差异运行配对t检验
6. 检查：均值差异与0有显著不同吗？
7. 计算均值差异的置信区间
8. 计算效应量（Cohen's d）判断实际显著性
```

### 统计显著性 vs 实际显著性

结果可以统计显著但实际上无意义。有足够的数据，即使是微不足道的差异也会变得统计显著。

```
示例：
  模型A准确率: 0.9234
  模型B准确率: 0.9237
  n = 1,000,000个测试样本
  p值 = 0.001

统计显著？是的。
实际显著？0.03%的改进不值得部署新模型的工程成本。
```

**效应量** 独立于样本大小量化差异有多大：

```
Cohen's d = (均值1 - 均值2) / 合并标准差

d = 0.2:  小效应
d = 0.5:  中等效应
d = 0.8:  大效应
```

**始终同时报告p值和效应量。** p值告诉你差异是否真实，效应量告诉你差异是否重要。

### 多重比较问题

当你测试多个假设时，某些会碰巧"显著"。如果你以alpha = 0.05测试20件事，即使什么都不是真实的，你也预期有1个假阳性。

```
P(至少一个假阳性) = 1 - (1 - alpha)^m

m = 20个测试，alpha = 0.05:
P(假阳性) = 1 - 0.95^20 = 0.64

你有64%的机会得到至少一个假阳性。
```

**Bonferroni校正：** 将alpha除以测试数量。

```
调整后alpha = alpha / m = 0.05 / 20 = 0.0025

只有当 p值 < 0.0025 时才拒绝H0。
保守但简单。在测试独立时有效。
```

在ML中，当你在多个指标上比较模型、测试多个超参数配置或在多个数据集上评估时，这很重要。

### 自助法（Bootstrap）

自助法通过有放回地重采样数据来估计统计量的抽样分布，不需要对基础分布做任何假设。

**算法：**

```
1. 你有n个数据点
2. 有放回地抽取n个样本（某些点出现多次，某些不出现）
3. 在这个自助样本上计算你的统计量
4. 重复B次（通常B = 1000到10000）
5. 自助统计量的分布近似于抽样分布
```

**自助置信区间（百分位数方法）：**

```
排序B个自助统计量
95% CI = [第2.5百分位, 第97.5百分位]
```

**为什么自助法对ML重要：**

```
- 测试集准确率是点估计。自助法给你置信区间。
- 你不能假设指标分布是正态的（尤其是AUC、F1、top-k精确率）。
- 自助法适用于任何统计量：中位数、两均值之比、
  两模型AUC的差异。
- 不需要封闭形式的公式。
```

**用于模型比较的自助法：**

```
1. 你有模型A和模型B在同一测试集上的预测
2. 对于每次自助迭代：
   a. 有放回地重采样测试索引
   b. 在重采样集上计算metric_A和metric_B
   c. 存储 diff = metric_B - metric_A
3. 差异的95% CI：
   [diff的第2.5百分位, diff的第97.5百分位]
4. 若CI不包含0，差异显著
```

这比配对t检验更鲁棒，因为它不做分布假设。

### 参数检验 vs 非参数检验

**参数检验** 假设特定分布（通常是正态分布）：

```
t检验:          假设数据服从正态分布（或大n时由CLT保证）
方差分析（ANOVA）: 假设正态性和等方差
Pearson r:      假设二元正态分布
```

**非参数检验** 不做分布假设：

```
Mann-Whitney U:     比较两组（替代独立t检验）
Wilcoxon符号秩:      比较配对数据（替代配对t检验）
Spearman rho:       基于排名的相关（替代Pearson）
Kruskal-Wallis:     比较多组（替代ANOVA）
```

**何时使用非参数：**

```
- 样本量小（n < 30）且数据明显非正态
- 有序数据（评分、排名）
- 存在无法移除的严重异常值
- 偏斜分布
```

**何时使用参数：**

```
- 大样本量（CLT使检验统计量近似正态）
- 数据大致对称，无极端异常值
- 更高的统计功效（更好地检测真实差异）
```

在ML实验中，你通常n很小（5或10个交叉验证折），因此Wilcoxon符号秩等非参数检验通常比t检验更合适。

### 中心极限定理：实践含义

CLT说样本均值的分布随着n增大会趋向正态分布，无论基础总体分布如何。

```
若X_1, X_2, ..., X_n是均值mu、方差sigma^2的独立同分布变量：

    X_bar ~ Normal(mu, sigma^2 / n)    当n -> 无穷时

大多数情况下n >= 30就有效。
对于高度偏斜的分布，可能需要n >= 100。
```

**为什么这对ML重要：**

```
1. 为聚合指标上的置信区间和t检验提供理论依据
2. 解释为什么即使单个折变化很大，
   对交叉验证折取平均也能给出稳定估计
3. 小批量梯度下降之所以有效，是因为批次上的平均梯度
   近似真实梯度（CLT在起作用）
4. 集成方法：对许多模型的预测取平均比任何单个模型
   给出更稳定的输出
```

**CLT不做什么：**

```
- 不使你的数据正态化，它使样本均值正态化
- 不适用于方差无限的重尾分布（柯西分布）
- 不适用于相关数据（时间序列，不校正的情况下）
```

### ML论文中常见的统计错误

1. **在训练集上测试。** 保证过拟合。始终预留模型在训练期间从未见过的数据。

2. **没有置信区间。** 报告单个准确率数字而不报告不确定性使结果不可复现和不可验证。

3. **忽略多重比较。** 测试50种配置并报告最佳结果而不校正，会虚增假阳性率。

4. **混淆统计和实际显著性。** 0.01%准确率提升的p值0.001没有意义。

5. **在不平衡数据上使用准确率。** 99%负类的数据集上99%准确率意味着模型什么都没学。使用精确率、召回率、F1或AUC。

6. **挑选指标（Cherry-picking）。** 只报告模型获胜的指标。诚实的评估报告所有相关指标。

7. **跨训练/测试划分泄漏信息。** 划分前归一化，或用未来数据预测过去。

8. **无方差估计的小测试集。** 在100个样本上评估并声称2%的改进是噪声，不是信号。

9. **数据不独立时假设独立性。** 来自同一患者的医学图像、来自同一文档的多个句子——组内观测是相关的。

10. **p-hacking。** 尝试不同的检验、子集或排除标准，直到得到p < 0.05。结果是搜索的产物。

## 关键术语

| 术语 | 含义 |
|------|------|
| 均值（Mean） | 所有值的和除以计数。对异常值敏感。 |
| 中位数（Median） | 排序数据的中间值。对异常值鲁棒。 |
| 标准差（Standard deviation） | 方差的平方根，以原始单位衡量离散程度。 |
| 百分位数（Percentile） | 给定百分比的数据低于这个值。 |
| IQR（四分位距） | Q3减Q1，中间50%数据的离散程度。 |
| Pearson相关 | 测量两个变量之间的线性关联。范围[-1, 1]。 |
| Spearman相关 | 使用排名测量单调关联。 |
| 协方差矩阵（Covariance matrix） | 所有特征之间成对协方差的矩阵。 |
| 零假设（Null hypothesis） | 无效果或无差异的默认假设。 |
| p值（p-value） | 在零假设为真时，数据如此极端的概率。 |
| 置信区间（Confidence interval） | 给定置信水平下参数的合理值范围。 |
| t检验（t-test） | 检验均值是否显著不同，使用t分布。 |
| 卡方检验（Chi-squared test） | 检验观察频率是否与期望频率不同。 |
| 效应量（Effect size） | 差异的大小，独立于样本大小。Cohen's d是常见选择。 |
| Bonferroni校正 | 将显著性阈值除以测试次数，以控制假阳性。 |
| 自助法（Bootstrap） | 有放回地重采样以估计抽样分布。 |
| I类错误（Type I error） | 假阳性。H0为真时拒绝H0。 |
| II类错误（Type II error） | 假阴性。H0为假时未能拒绝H0。 |
| 统计功效（Statistical power） | 正确拒绝虚假H0的概率。功效 = 1 - II类错误率。 |
| 中心极限定理（Central limit theorem） | 随着样本量增大，样本均值收敛到正态分布。 |
| 参数检验（Parametric test） | 假设数据具有特定分布（通常是正态）。 |
| 非参数检验（Non-parametric test） | 不做分布假设。基于排名或符号。 |
