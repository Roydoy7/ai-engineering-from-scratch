# 梯度累积（Gradient Accumulation）

> 以你负担不起的有效批次训练，一次一个微批次。缩放损失，保留优化器步骤，让梯度积累起来。

**类型：** 构建  
**语言：** Python  
**前置知识：** Phase 19 第 42-45 课  
**预计时间：** 约 90 分钟

## 学习目标

- 推导有效批次恒等式：`effective_batch = micro_batch * accum_steps`。
- 实现每微批次损失缩放，使积累的梯度与单个全批次反向传播匹配。
- 跳过优化器同步直到最后一个微批次（在最后一步同步）。
- 读取对有效批次的吞吐量曲线，解释递减回报。

## 核心概念

```mermaid
flowchart LR
  start[开始] --> zero[清零梯度]
  zero --> mb1[微批次 1：前向 + 缩放反向]
  mb1 --> mb2[微批次 2：前向 + 缩放反向]
  mb2 --> dots[...]
  dots --> mbN[微批次 N：前向 + 缩放反向 + 同步]
  mbN --> step[优化器步骤]
  step --> next[下一个有效步骤]
```

契约很简单：

- 每个微批次的损失在 `backward()` 之前除以 `accum_steps`。
- 优化器步骤在最后一个微批次的反向传播之后，每个有效批次触发一次。
- 优化器状态每个有效步骤前进一次，而非每个微批次。
- 在多排集群上，非最终微批次在 `no_sync` 上下文中包装，跳过梯度全规约；最后一个微批次在一次通过中归约完整积累的梯度。

**等效性证明**：单次全批次反向传播等价于 N 个微批次反向传播，每个微批次损失除以 N。课程代码通过最大绝对差 < 1e-4 的断言来验证这一点。

## 关键术语

| 术语 | 通俗说法 | 准确含义 |
|------|----------|----------|
| Micro batch（微批次） | "你前向传递的批次" | 在单次前向传递中适合内存的切片 |
| Accum steps（累积步骤） | "每步的反向传播次数" | 一个优化器步骤之前求和的反向传播次数 |
| Effective batch（有效批次） | "批次" | 微批次乘以累积步骤乘以数据并行世界大小 |
| Loss scaling（损失缩放） | "除以 N" | 每微批次除法，使求和的梯度与全批次匹配 |
| Sync on last（最后同步） | "跳过其余" | 只在窗口中最后一个反向传播时运行梯度集合通信 |
