# LLM 的差分隐私（Differential Privacy for LLMs）

> DP-SGD 仍然是标准——注入噪声的梯度更新提供形式化的（epsilon, delta）保证。计算、内存和效用方面的开销很大；参数高效的 DP 微调（LoRA + DP-SGD）是 2025 年的常见配置（ACM 2025）。两个存在张力的证据体：基于金丝雀的成员推断（Duan 等人，2024 年）报告对语言模型的成功有限；训练数据提取（Carlini 等人，2021 年；Nasr 等人，2025 年）恢复了大量逐字记忆。解决方案（arXiv:2503.06808，2025 年 3 月）：差距在于测量内容——插入的金丝雀 vs "最可提取"的数据。新的金丝雀设计在没有影子模型的情况下实现了基于损失的 MIA，并在使用真实数据训练的 LLM 上进行了首次非平凡的 DP 审计，具有现实的 DP 保证。替代方案：PMixED（arXiv:2403.15638）——在推理时通过下一个 token 分布的专家混合实现私有预测；DP 合成数据生成（谷歌研究，2024 年）。新兴攻击：通过 LLM 反馈的差分隐私反转——置信度分数泄露。

## 问题所在

LLM 会记忆。Carlini 等人 2021 年表明生产语言模型在被提示时会逐字复现训练文本。DP 是形式化防御：训练时使输出对任何单个训练示例的敏感性可证明地低。2024-2025 年的证据表明 DP-SGD 是必要的，但部署的 ε 值可能与威胁模型不匹配。

## 核心概念

### (ε, δ)-差分隐私

随机算法 M 是 (ε, δ)-DP 的，如果对任何相差一个样本的两个数据集和任何事件 S：
P(M(D) 在 S 中) <= e^ε * P(M(D') 在 S 中) + δ。

解释：输出分布足够接近（由 ε 参数化），以至于任何单个个体的贡献都无法被可靠地推断，除了概率 δ 的情况。

### DP-SGD

Abadi 等人，2016 年。标准方案：
1. 采样一个小批次。
2. 计算每个示例的梯度。
3. 将每个示例的梯度裁剪到阈值 C。
4. 对裁剪后的梯度求和并添加标准差为 σ * C 的高斯噪声。
5. 使用有噪声的总和更新参数。

隐私成本由计账器跟踪（矩计账器、Rényi DP 计账器）。LLM 文献中报告的 ε 值因威胁模型、数据敏感性和效用目标而有很大差异；没有普遍"安全"的默认 ε。一些 LLM 训练设置中发布的示例大致在 ε ≈ 1-10 范围内，但这些是说明性的——不是推荐的默认值。较低的 ε 通常需要更多的噪声并且可能增加效用损失。

### LoRA + DP-SGD

对前沿模型进行完整的 DP-SGD 是禁止性的。LoRA（Hu 等人，2022 年）将梯度更新限制为小型适配器，减少了每个示例的梯度存储。LoRA + DP-SGD 是 2025 年的常见配置。DP 保证适用于适配器；基础模型保持固定。

### 2024-2025 年的张力

两条证据线：

- **金丝雀 MIA（Duan 等人，2024 年）。** 将唯一的金丝雀插入训练数据，测量成员推断攻击者是否能识别它们。报告对语言模型的成功有限。表明 MIA 很难。
- **训练数据提取（Carlini 2021，Nasr 等人，2025 年）。** 用前缀提示模型；测量它是否从训练中恢复逐字文本。报告大量记忆。表明 MIA 在相关意义上很容易。

2025 年 3 月的解决方案（arXiv:2503.06808）：两者测量的是不同的东西。MIA 在插入的金丝雀上询问"示例 e 是否在 D 中"。提取询问"我能从 D 中恢复什么"。"最可提取"的示例才是隐私的关键；金丝雀低估了这一点，因为它们没有针对可提取性进行优化。

新的金丝雀设计。无需影子模型的基于损失的 MIA。首次对具有现实 DP 保证的真实数据上训练的 LLM 进行非平凡 DP 审计。

### DP 训练的替代方案

- **PMixED（arXiv:2403.15638）。** 推理时私有预测。下一个 token 分布上的专家混合；每个专家看到训练数据的一个分片；聚合添加噪声以实现 DP。完全避免 DP 训练。
- **DP 合成数据生成（谷歌研究，2024 年）。** 用 DP-SGD 进行 LoRA 微调，采样合成数据，在合成数据上训练下游分类器。

两者都以不同的威胁模型为代价，绕开了完整 DP 训练的效用成本。

### 通过 LLM 反馈的差分隐私反转

2025 年新兴攻击。使用 DP 训练模型的置信度分数作为预言机来重新识别个体。即使输出不泄露，置信度分布也可以。

防御：不暴露置信度，或在暴露前截断/量化它们。这是超出 (ε, δ)-DP 训练的额外要求。

## 使用它

`code/main.py` 在玩具二元分类数据集上模拟 DP-SGD。你可以调整噪声乘数 σ 和裁剪范数 C，并跟踪 (ε, δ) 预算和准确率成本。"金丝雀攻击"插入一个唯一的训练示例，并测量对数损失测试在 DP 之前和之后是否能检测到它。

## 交付它

本课产出 `outputs/skill-dp-audit.md`。给定语言模型部署上的 DP 声明，审计：(ε, δ) 值、使用的计账器、MIA 评估协议，以及是否已评估置信度暴露向量。

## 练习

1. 运行 `code/main.py`。在 σ ∈ {0.5, 1.0, 2.0} 中调整，并报告 (ε, δ)-准确率权衡。识别效用崩溃的点。

2. 实现金丝雀插入和对数损失测试。在 σ = 1.0 时测量 DP-SGD 前后的检测率。

3. 阅读 Nasr 等人 2025 年关于训练数据提取的研究。为什么在适度 ε 下提取成功率不会崩溃？这对 MIA 作为评估意味着什么？

4. 设计使用 PMixED（arXiv:2403.15638）的完全在推理时运行的部署。PMixED 解决的是 DP-SGD 不解决的什么威胁模型？

5. 勾勒通过 LLM 反馈的 DP 反转攻击。设计一个限制置信度分数泄露的对策，并估计其部署成本。

## 关键术语

| 术语 | 通俗说法 | 准确含义 |
|------|----------|----------|
| DP | "(ε, δ)-差分隐私" | 形式化隐私：输出分布在邻近数据集变化下接近 |
| DP-SGD | "注入噪声的 SGD" | 梯度裁剪 + 高斯噪声添加；标准 DP 训练 |
| LoRA + DP-SGD | "高效私有微调" | 低秩适配器上的 DP-SGD；2025 年标准配置 |
| MIA | "成员推断" | 确定示例是否在训练数据中的攻击 |
| Canary（金丝雀） | "插入的水印示例" | 用于测量 DP 泄露的唯一训练示例 |
| PMixED | "私有推断混合" | 通过下一个 token 分布的专家混合在推理时实现 DP |
| DP Reversal（DP 反转） | "置信度泄露攻击" | 使用模型置信度作为重新识别预言机的攻击 |
